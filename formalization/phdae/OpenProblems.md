# 非线性 pH-DAE 形式化：核心开放问题

> 2026.05 | 经多轮推敲修正

---

## 已确认的结果

**机器验证（KeYmaera X）**：
- 全无源非线性两机 pH 系统：Lyapunov 稳定性、渐近稳定性
- 充要条件 D > 0 ∧ K > 0（渐近稳定的存在性）
- 非线性能量平衡 Ḣ = -D₁ω₁² - D₂ω₂²（pH 的 J 反对称性使 sin 项精确抵消）
- 保守系统稳定域 H < 4K（鞍点能量，精确充要）

**分析得到（纸笔 + 数值验证）**：
- 线性化稳定性边界 |D₂| < min(D₁, K/2)（小信号，含非无源）
- sin 限幅效应：非线性系统在弱电网下比线性预测更稳定
  （sin 的有界性限制了耦合增益，削弱了非无源组件的能量抽取）

**推翻的错误结论**：
- Schur 补标量模型的稳定性边界（符号搞反 + 模型不代表电力系统）
- 一阶摄动近似 H_crit ≈ 4K + 8D√K（数值交叉验证证明误差 30-80%）
- "Q 奇异是 pH-DAE 的结构性困难"（实为坐标选择问题）
- "Dirac 组合有额外困难"（实为逐点应用，无问题）

## 唯一的核心开放问题

### D₂ < 0 时非线性大信号稳定性

当系统含非无源组件（PLL 变换器，等效 D₂ < 0）时：

$$\dot{H} = -D_1\omega_1^2 + |D_2|\omega_2^2$$

H 不是 Lyapunov 函数。

#### 已知
- 小信号边界：|D₂| < min(D₁, K/2)（特征值分析，已验证）
- 非线性效应使实际稳定域**大于**线性预测（sin 限幅，数值验证）
- 修正 Hamiltonian V = H + α(ω₁-ω₂)sin δ 对 D₂ < 0 不可行
  （交叉项无法同时在 ω 和角度方向提供耗散）

#### 不知道
- 非线性大信号稳定域的精确刻画（闭式或可计算的充要条件）
- sin 限幅效应的精确量化条件
- 是否存在适用于 D₂ < 0 的非标准 Lyapunov 函数

#### 可能的方向
1. SOS/neural 方法搜索非标准 Lyapunov 函数 → KeYmaera X 验证
2. 区域化分析：不同 δ 范围用不同论证，域约束连接
3. pH 代数抵消（Ḣ 无 sin）+ IQC/S-procedure 处理 (D₁, D₂) 二次型
4. 利用 sin 有界性构造 gain-scheduled Lyapunov 函数

## 形式化的价值

形式化在这个过程中的作用不是"验证已知结论"，而是：
- 精确定位了理论边界（修正 Hamiltonian 对 D₂<0 不可行——已证）
- 发现了错误（Schur 补符号错、摄动公式不准确——被交叉验证捕捉）
- 排除了假问题（Q 奇异、Dirac 组合——经推敲确认不是真问题）
- 将开放问题压缩到一个精确表述
