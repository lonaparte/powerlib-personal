# 电力电子化电力系统的形式化：已验证的认知

> 2026.05 | 只包含经过验证的结论和诚实的未知

---

## 做了什么

对两机非线性系统（sin 耦合、droop 阻尼）用 KeYmaera X 和数值分析做了完整的稳定性探索。

### 系统

$$\dot{\delta} = \omega_1 - \omega_2, \quad \dot{\omega}_1 = -D_1\omega_1 - \tfrac{K}{2}\sin\delta, \quad \dot{\omega}_2 = -D_2\omega_2 + \tfrac{K}{2}\sin\delta$$

这是消去代数变量后的约化 ODE，不是 DAE。

---

## 已验证的结论

### 1. pH 结构使能量平衡中 sin 项精确抵消

$$\dot{H} = -D_1\omega_1^2 - D_2\omega_2^2$$

KeYmaera X 机器验证。对任意 δ 精确成立，不需线性化。来源是 J 反对称性。

### 2. D₁ > 0, D₂ > 0 时的完整稳定性

- **Lyapunov 稳定性**：H 的亚水平集正不变。KeYmaera X 证明。
- **渐近稳定性**：修正 Hamiltonian V = H + (ω₁-ω₂)sinδ/4 在 {cosδ > 0} 域内严格负定。KeYmaera X 证明（K=D=1 固定值，15.6 秒）。
- **稳定域**：保守系统（D=0）精确为 H < 4K。耗散系统更大但无闭式。
- **充要条件**：D > 0 ∧ K > 0 是渐近稳定性存在的充要条件（充分性和三个必要性方向均 KeYmaera X 证明）。

### 3. D₂ < 0 时 H 不是 Lyapunov 函数

Ḣ = -D₁ω₁² + |D₂|ω₂² 在 ω₂ 方向正定。解析显然。
V = H + α(ω₁-ω₂)sinδ 形式的修正也不行（数值验证，所有测试的 α 和 D₂ 值均失败）。

### 4. D₂ < 0 时 Lyapunov 函数仍存在（但不来自 pH）

线性化的 Lyapunov 方程 A'P + PA = -I 给出正定 P。V = x'Px 是局部 Lyapunov 函数。
非线性稳定域通过 Taylor 余项估计：

| D₂ | 稳定域半径 |
|----|----------|
| -0.1 | 0.76 rad (44°) |
| -0.3 | 0.45 rad (26°) |
| -0.49 | 0.08 rad (5°) |

D₂ 趋近临界值时稳定域收缩到零。

### 5. 小信号稳定性边界

$$|D_2| < \min\!\left(D_1,\; \frac{K}{2D_1}\right)$$

由 Routh-Hurwitz 解析推导，12 组 (D₁, K) 参数值数值验证全部吻合。

## 已排除的假问题

| 声称的问题 | 排除原因 |
|-----------|---------|
| Q 矩阵奇异 | 全局角度平移对称性，固定参考角后 Q 正定（det=1） |
| Dirac 结构组合困难 | 逐点应用即可，无额外困难 |
| Schur 补标量模型的稳定性边界 | 模型不代表电力系统 + 符号搞反，结论完全错误 |
| 摄动公式 H_crit ≈ 4K + 8D√K | 数值交叉验证误差 30-80% |
| sin 限幅使线性不稳定系统非线性稳定 | 仿真时间不足导致的假象，更长时间仿真推翻 |

## 不知道的

### 核心问题

D₂ < 0 时，pH 结构给出 Ḣ = -D₁ω₁² + |D₂|ω₂²（有用的代数信息），但不能直接用于稳定性证明。经典 Lyapunov（x'Px）可以局部使用但不利用 pH 结构。

**这两者之间有没有桥梁？**

### 已验证：Lur'e 理论不直接适用

系统 ẋ = Ax + b·sin(c'x) 确实是 Lur'e 形式（线性 + 扇区非线性反馈）。
φ(σ) = sinσ - σ 在扇区 [-1.22, 0] 内（精确下界 sinσ/σ 的 inf = -0.217）。

但两种标准判据都失败：
- **分解 1**（φ = sinδ - δ，A 含线性耦合）：A 是 Hurwitz，但 min Re[G(jω)] 远小于 -1/α = 0.82。圆判据不满足。D₂=-0.1 时 min Re[G] = -2.5。
- **分解 2**（φ = sinδ，A 不含耦合）：A 不是 Hurwitz（有零特征值和正特征值），标准圆判据不适用。
- **Popov 判据**：对所有测试的 q ≥ 0 均不满足。

原因：这些判据是**充分条件**，对这个系统太保守。不是说系统不稳定，而是这些工具不够强。更精细的工具（Zames-Falb 乘子、IQC）可能有效，但需要进一步验证。

### 没做到的

- 没有在 DAE 层面（不消去代数变量）直接做分析
- 没有做 N > 2 台机器的情况
- 没有做异构设备（构网 + 跟网 + 同步机混合）
- 没有做实际控制器结构（PLL 的具体动态，而非等效负阻尼）
- 形式化验证只覆盖了全无源的简单情况

## 方法论认知

1. **形式化验证（KeYmaera X）对全无源 pH 系统非常有效**。dI + dC + QE 可以自动证明 Lyapunov 和渐近稳定性。微分不变量绕过了 ODE 解理论。

2. **pH 结构的真正价值是代数简化**：sin 项的精确抵消将非线性能量分析化简为二次型问题。但这不等于稳定性——二次型不定时需要额外工具。

3. **交叉验证是必需的**。每一个未经验证的结论都有可能是错的。这次发现的错误包括：符号搞反、公式只对特定参数正确、仿真时间不足造成假象。

4. **"难点在哪"这个问题本身需要不断修正**。从最初的"10个障碍"到最后的"1个核心问题"，每一轮推敲都排除了假问题或发现了新问题。当前的认知仍可能有错。
