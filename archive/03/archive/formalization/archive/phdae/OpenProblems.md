# 非线性 pH-DAE 形式化：经验证的问题清单

> 2026.05 | 每条结论都经过数值或形式化验证

---

## 已确认的事实

### 1. pH 的 J 反对称性使 sin 项精确抵消（KeYmaera X 已证）
$$\dot{H} = -D_1\omega_1^2 - D_2\omega_2^2$$
不含 sin/cos 项。对任意 δ 成立，不需线性化。

### 2. D₁ > 0, D₂ > 0 时 H 是 Lyapunov 函数（KeYmaera X 已证）
Ḣ ≤ 0，稳定域 H < 4K（保守系统精确充要，耗散系统充分）。

### 3. D₂ < 0 时 H 不是 Lyapunov 函数（数值验证）
Ḣ = -D₁ω₁² + |D₂|ω₂² 在 ω₂ 方向正定，任意小邻域内都有 Ḣ > 0 的点。

### 4. V = H + α(ω₁-ω₂)sinδ 形式的修正对 D₂ < 0 不可行（数值验证）
对所有测试的 α∈{0.01, 0.05, 0.1, 0.2, 0.3} 和 D₂∈{-0.1, -0.2, -0.3, -0.4}，
V̇ 在任意小的球内都不是 ≤ 0。原因：V̇ 的主项（线性化后）仍含 +2|D₂|ω₂²，
修正项是高阶量，在原点附近被主项支配。

### 5. Lyapunov 函数存在但不来自 pH（数值验证）
解 Lyapunov 方程 A'P + PA = -I 得到正定 P，V = x'Px 是局部 Lyapunov 函数。
对 |D₂| < min(D₁, K/2) 的所有测试值，P 都存在且正定。
但 P ≠ Hessian(H)——P 有大量交叉项，且条件数随 D₂→D₂_crit 而趋于无穷。

### 6. 小信号稳定性边界（特征值分析，数值验证）
|D₂| < min(D₁, K/2)

### 7. 非线性稳定域依赖 K 和 D₂ 的方式不同于线性预测（数值验证）
- K=1, D₂=-0.3（线性稳定✓）：非线性稳定域 |ω₀| < 1.6
- K=1, D₂=-0.49（线性稳定✓）：非线性稳定域 |ω₀| < 0.2（接近边界时域极小）
- K=0.1, D₂=-0.06（线性不稳定✗）：非线性仍稳定 |ω₀| < 0.2（sin 限幅效应）
- K=0.1, D₂=-0.08（线性不稳定✗）：非线性不稳定

### 8. Q 奇异是坐标问题（分析验证）
零空间方向 = 全局角度平移 (1,1,0,0,1)。用相对坐标消除。
θ_m 方向 ∂²H/∂θ_m² = 2K ≠ 0，不是零。

### 9. Dirac 组合逐点成立（理论确认）
状态依赖的 Dirac 结构组合 = 对每个状态值独立应用常数 Dirac 组合定理。

## 开放问题

### A. 非线性大信号稳定域的估计（D₂ < 0）

**已知**：线性化 Lyapunov 矩阵 P 存在（事实 5）。
V = x'Px 是局部 Lyapunov 函数。

**问题**：V = x'Px 对非线性系统给出多大的稳定域？
具体：V̇_nonlinear = V̇_linear + 高阶项。高阶项在什么范围内可忽略？
亚水平集 {x'Px < c} 对多大的 c 是正不变的？

**方法**：这可以用 KeYmaera X 验证——对具体的 P（已知数值），
验证 V̇ ≤ 0 在 {V < c, |δ| < δ_max} 域内。c 和 δ_max 是待确定的参数。

### B. sin 限幅效应的精确条件

**已知**：K=0.1, D₂=-0.06 时线性不稳定但非线性稳定（事实 7）。

**问题**：什么条件下非线性稳定域严格大于线性预测？
sin 的有界性对能量传输的限制能否解析量化？

**可能的方向**：
- describing function：sin 的等效增益 = sinc(amplitude)
- 在大振幅下 sinc < 1，等效耦合减弱
- 等效 D₂_crit 变为关于振幅的函数

### C. pH 结构对 D₂ < 0 的残余价值

**已知**：H 不是 Lyapunov，但 Ḣ = -D₁ω₁²-D₂ω₂²（sin 项抵消）仍成立。

**问题**：pH 结构在 D₂ < 0 时还提供什么信息？
- Ḣ 的公式（sin 项抵消）是否可以和其他方法结合？
- 比如：Ḣ = -D₁ω₁²+|D₂|ω₂² 是关于 (ω₁,ω₂) 的二次型，
  和 V̇ = -x'x（来自 Lyapunov 方程）结合，能否给出更好的估计？

### D. P 矩阵的物理解释

**已知**：P 来自解 A'P+PA=-I，数值上有大量交叉项。

**问题**：P 的结构和物理参数 (D₁, D₂, K) 的关系是什么？
- P 的条件数 → ∞ 当 D₂ → D₂_crit 意味着什么？
- P 的交叉项是否对应某种"混合能量"？
- 能否从 pH 的 (J, R) 结构推导 P 的性质？

## 已排除的假问题

- Q 奇异（坐标问题，事实 8）
- Dirac 组合困难（逐点成立，事实 9）
- Schur 补标量模型（模型错误，符号搞反，已推翻）
- 一阶摄动公式 H_crit ≈ 4K+8D√K（数值误差 30-80%，已推翻）

## 方法论收获

1. 形式化验证（KeYmaera X）对全无源系统完全有效
2. D₂ < 0 时 pH 框架本身不够，需要额外工具（Lyapunov 方程 / SOS）
3. 数值交叉验证是必需的——没有它会带着错误结论走很远
4. 每次"推敲"都发现了错误或假问题——说明直觉不可靠
5. 线性化和非线性分析给出不同结论——弱电网下差异显著
