# 修正技术路线：PHS + 五原型路径

> 2026.05 | 基于 PHS 绕开大部分分析学障碍的重构方案

---

## 核心洞察

Port-Hamiltonian 系统将稳定性分析从**分析学问题**降级为**线性代数问题**：

- 能量平衡 `Ḣ = -∇H'R∇H + y'u` 是**逐点代数恒等式**，不依赖 ODE 解的存在性
- 无源性**内建于结构**（J 反对称 + R 半正定 → Ḣ ≤ y'u）
- 组合稳定性**内建于 Dirac 结构**（PHS 互联仍是 PHS，H_total = ΣH_i）
- 电网（Kirchhoff 定律）天然是 Dirac 结构

五原型理论进一步将问题从"任意非线性系统"收缩到"5 种参数化 PHS"。

---

## 障碍点对照（旧路线 vs PHS 路线）

| 障碍点 | 旧路线状态 | PHS 路线状态 | 说明 |
|--------|-----------|-------------|------|
| Lyapunov 函数构造 | 核心障碍 | **消除** | H 就是 Lyapunov 函数 |
| V̇ ≤ 0 的证明 | 需沿轨迹求导+三角函数化简 | **代数化** | 只需证 J=-J' 和 R≥0 |
| ODE 解全局存在循环依赖 | 需解延拓+Zorn | **大幅简化** | H≥0 且 Ḣ≤0 → 有界，不依赖解先存在 |
| 无源性理论 | 需从头建 | **内建** | PHS 结构自动保证无源 |
| 组合稳定性 | 需 assume-guarantee 框架 | **内建** | Dirac 结构组合保持 PHS |
| 三角函数不等式 (O(N²)) | Richardson 不可判定 | **可能消除** | 能量坐标避免 sin/cos |
| LaSalle 不变性原理 | 需从头形式化 | **简化为线性代数** | 退化为 (J-R, R^{1/2}) 可检测性 |
| DAE 框架 | 需组装 | **自然处理** | 网络约束 = Dirac 结构 |
| Laplace 变换 | 频域方法需要 | **不需要** | PHS 纯时域/能量域 |
| 奇异摄动 | 所有证明助手空白 | **仍需公理化** | 模型层级关系仍断裂 |

**10 个障碍中，6 个消除，2 个大幅简化，1 个不需要，1 个不变。**

## PHS 路线的剩余障碍

### 1. 渐近稳定性（简化但未消除）

PHS 给出 Ḣ = -∇H'R∇H ≤ 0（半负定），只能证 Lyapunov 稳定性。
渐近稳定性需要额外论证：

**线性 PHS 情况**：退化为 (J-R, R^{1/2}) 的可检测性/可观性——纯线性代数条件，Mathlib 可处理。

**非线性 PHS 情况**：仍需 LaSalle 或等价物。但论证范围缩小了很多——
只需在 {∇H'R∇H = 0} 的集合上分析不变性，不需要一般性的 LaSalle 理论。

**估计**：比完整 LaSalle 形式化简单一个量级。~500 行 vs ~2000 行。

### 2. 平衡点处 Hessian 正定性

稳定性需要 H 在平衡点 x* 有严格极小。对非二次 H（如含 -cos δ 项）：
- 需条件：|δ| < π/2（功率角在合理范围内）
- 需证 Hessian ∂²H/∂x² 在 x* 处正定
- 这是有限维矩阵的正定性——Mathlib 可处理（`fin_cases` + 数值/符号验证）

### 3. 非 PHS 子系统（PLL）

跟网变换器的 PLL 不天然是 PHS：
- PLL 本质是一个非线性振荡器（相位锁定环）
- 在某些频率范围内呈负阻抗（反无源）
- 需要特殊处理：
  - (a) 证明在特定条件下 PLL 可近似为 PHS（扰动论证）
  - (b) 或用 shortage of passivity 量化非无源度，再用小增益/IQC 方法

**如果五原型将 PLL 跟网变换器归为一种原型，则该原型的 PHS 表示本身就包含了这种近似。**

### 4. 奇异摄动（不变）

模型层级之间的形式关系仍然断裂。PHS 不帮助解决这个问题。
短期策略不变：公理化"平均模型有效"。

## 五原型 × PHS = 有限形式化

### 袁小明的幅相运动方程框架

每种设备的动力学统一为质量-弹簧-阻尼模型：

```
相位动力学：  J_p · δ̈ + D_p · δ̇ + K_p · δ = ΔP
幅值动力学：  J_a · V̈ + D_a · V̇ + K_a · V = ΔQ
```

其中 (J, D, K) 由设备类型和控制参数决定。

### 这是二阶 PHS

质量-弹簧-阻尼系统天然是 Port-Hamiltonian 的：

```
H = (1/2)J·ω² + (1/2)K·δ²    (动能 + 势能)

状态 x = (δ, p=Jω)

J_matrix = [0, 1; -1, 0]      (反对称 → 保守互联)
R_matrix = [0, 0; 0, D]        (半正定 → 耗散)

ẋ = (J_matrix - R_matrix) ∇H + g·u
```

### 五种原型（推测性，需你确认）

| 原型 | 设备类型 | J (惯量) | D (阻尼) | K (弹性) | 来源 |
|------|---------|---------|---------|---------|------|
| 1 | 同步发电机 | 物理转子惯量 | 阻尼绕组 | 同步转矩 | 物理 |
| 2 | 虚拟同步机 (VSM) | 虚拟惯量 | droop 系数 | 虚拟同步转矩 | 控制 |
| 3 | PLL 跟网变换器 | PLL 等效惯量 | PLL 阻尼 | PLL 等效刚度 | 控制 |
| 4 | 双馈风机 (DFIG) | 等效惯量 | 等效阻尼 | 等效刚度 | 混合 |
| 5 | LCC-HVDC | 等效惯量 | 等效阻尼 | 等效刚度 | 控制 |

**每种原型只是 (J, D, K) 三个参数不同。** PHS 结构 $(J_{matrix}, R_{matrix}, H)$ 完全相同。

## 新形式化路线图

```
第一步：PHS 核心框架                          ~1200-2100 行
  ├── Dirac 结构定义 + 性质                    ~300-500
  ├── PHS 定义 + 能量平衡                      ~200-400
  ├── 组合定理 (PHS + Dirac → PHS)             ~500-800
  └── 稳定性 (H 有极小 → Lyapunov 稳定)        ~200-400

第二步：二阶 PHS（质量-弹簧-阻尼）             ~500-800 行
  ├── 定义二阶 PHS 结构
  ├── 证明能量函数 H = (1/2)Jω² + (1/2)Kδ² 的性质
  ├── 参数化稳定性条件：J>0, D>0, K>0
  └── 渐近稳定性的可检测性条件

第三步：五原型实例化                           ~500-1000 行
  ├── 每种原型 = 具体的 (J,D,K) 参数化
  ├── 各原型到二阶 PHS 的映射
  └── 参数约束下的稳定性条件

第四步：网络互联                               ~500-800 行
  ├── 电网关联矩阵 → Dirac 结构
  ├── Kirchhoff 定律 = Dirac 性质
  └── 多原型组合 → 系统级 PHS

第五步：端到端验证                             ~500-1000 行
  └── N 台原型变换器通过网络互联
      参数满足条件 → 系统级稳定

总计：~3200-5700 行
```

| 指标 | 旧路线（一般 Lyapunov） | 新路线（PHS + 五原型） |
