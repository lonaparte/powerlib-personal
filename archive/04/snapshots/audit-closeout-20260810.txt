1. Q 通道的 +0.57% —— 是驱动变量错绑,不是理论误差   [scripts/mech9.py]
================================================================================

诊断。mech7 的 tensors5 把第五个展开变量硬编码成 V_,mech8 却把这套机器
直接用在 P / Q 通道上。于是无论驱动挂在哪个参数上,乘性(参数)算子永远
是 ∂²f/∂y∂V。

符号审计(在 Hopf 点求值)直接判定:

    u = V : 恒零 = False,  ‖∂²f/∂y∂V‖_max = 5.91192e+03
    u = P : 恒零 = True,   ‖·‖_max = 0.00000e+00
    u = Q : 恒零 = False,  ‖∂²f/∂y∂Q‖_max = 1.18238e+02
    cos∠(V,Q) = +0.01230

两条硬事实:
 (a) P 只经 P/C 进入直流母线平衡,∂f/∂P = e₃/C 与状态无关,所以
     ∂²f/∂y∂P ≡ 0,P 的乘性份额必须精确为零。mech8 打印 −0.02%,那是
     V 张量泄漏进 P 的运行。
 (b) V 与 Q 的混合二阶算子几乎正交(cos = 0.012)。所以 V-绑定的 Q 运行
     连"差一个标度"都不是,它用的是一个方向完全不同的算子。

按通道重建张量后(nf5drv.py 把驱动符号做成参数)重跑 G1 margin 0.10、
r = 0.90,对照 3000 周期收敛后的实测阈值:

    通道 |  仅可加   | 可加+乘性 | 乘性份额  | V-绑定(mech8)
    -----+-----------+-----------+-----------+---------------
     V   |  +0.14%   |  +0.03%   |  +0.44%   |  +0.03%
     P   |  +0.03%   |  +0.03%   |  +0.00%   |  +0.04%
     Q   |  +0.56%   |  +0.06%   |  +1.90%   |  +0.57%

P 的乘性增量精确为 +0.000000e+00,与符号审计一致。Q 自己的乘性增量是
+4.334475e+04(占 Re c_x 的 1.90%),V-绑定给出的是 −3.375993e+02 —— 量级
和符号都错。

结论:五阶闭式在三个通道上都是 ≤ +0.06%。上一轮"≤0.12% 只在 V/P 成立"
的撤回**再撤回**:它在 Q 上同样成立,之前的 +0.57% 是实现层的绑定 bug。

窗口偏差(1000 → 3000 周期)在三个通道上都是 +0.00%,所以这些数字不含
观测窗人为量。

2. 随机 / 宽带驱动 —— 侵蚀是谱上的标量和   [scripts/noise1.py, noise1b.py]
================================================================================

推导。把驱动写成多载波 u(t) = Σ_k (a_k e^{i w_k t} + c.c.)。约化 ζ 方程的
共振条件是

    D_π = j λ + k λ̄ + Σ_k (l_k − m_k) i w_k = λ

对不可通约的 w_k 只剩 j = k+1 且每个 k 满足 l_k = m_k。两条结论,都是免费的:

 (E1) 三次阶没有交叉侵蚀。指数 (l₁−m₁, l₂−m₂) = (+1, −1) 给出
      D − λ = i(w₁−w₂) ≠ 0,非共振。所以
          α_eff = α − Σ_k Re c_x(w_k) |a_k|²
      用的还是同一个 c_x(w),逐音求值。连续谱极限(单边 PSD S_u,
      ⟨u²⟩ = ∫S_u dw):
          α_eff = α − (1/2) ∫ Re c_x(w) S_u(w) dw
 (E2) 投入冲击是**相量和**不是标量和,因为各音共用同一通道方向 f_u,
      只有复分母不同:
          Z(0) = Σ_k 2 a_k λ ⟨p,f_u⟩ / (w_k² + λ²)

双音实测(G1 margin 0.10,V 通道,突发投入):

    w₁=0.90 w₂=0.90/φ  1:1        −0.13%    侵蚀分配 100.1 / −0.1
    w₁=0.90 w₂=0.90/φ  1:0.5      −0.01%                100.0 / −0.0
    w₁=0.90 w₂=1.30    1:1        −0.65%                 68.5 / 31.5
    w₁=0.90 w₂=0.45    1:1        +0.07%                101.8 / −1.8
    w₁=0.90 w₂=0.90/φ  反相       −0.21%                100.1 / −0.1

反相那一格是相量和的直接证据:同样的两个音,只把第二个音的相位翻 π,
阈值从 1.044e-4 抬到 1.345e-4(+29%),预测 −0.21%。标量和无法产生这个差别。

顺带一个不是设计出来的发现:Re c_x(w) **会变号**。w₂ = 0.90/φ ≈ 0.556 w₀
和 w₂ = 0.45 w₀ 两格的侵蚀分配是 −0.1% 和 −1.8%,即这些频率的驱动
**加固**守卫而不是侵蚀它。所以"任何扰动都削裕度"是错的,次谐波带的
驱动在这套机理下是稳定化的。

多音格的残差与其机理(noise1b)见第 6 节。

3. A2 五阶逃逸率 —— 闭式把 +0.82% 收到 +0.15%   [scripts/wrapA12.py]
================================================================================

径向方程 ρ' = −α_eff ρ + c1_eff ρ³ + Re c2 ρ⁵ 在守卫处的导数,用
α_eff = c1_eff ρ_g² + Re c2 ρ_g⁴ 消去 ρ_g:

    λ_u = −α_eff + 3 c1_eff ρ_g² + 5 Re c2 ρ_g⁴
        = 2 c1_eff ρ_g² + 4 Re c2 ρ_g⁴
        = 2 α_eff + 2 Re c2 ρ_g⁴          (三次极限即 λ_u = 2α)

对照**精确 Floquet 指数**(无驱动不稳定极限环,(点,周期) 系统上牛顿求解 +
单值矩阵),四个裕度:

    α     精确 λ_u      2α (三次)          五阶闭式
    0.05  0.09982328    0.10000024 +0.18%  0.09983124 +0.01%
    0.10  0.19924993    0.20000024 +0.38%  0.19932847 +0.04%
    0.15  0.29824131    0.30000009 +0.59%  0.29849796 +0.09%
    0.20  0.39673973    0.39999981 +0.82%  0.39734572 +0.15%

第二乘子在四格上都是 1.000000(平凡乘子),所以环确实找对了。

4. A1 投入冲击 —— 冲击是线性的,二次修正本来就不该加
                                     [scripts/wrapA12.py → wrapA1b.py → wrapA1c.py]
================================================================================

问题的提法。t = 0⁻ 系统在无驱动平衡点 y = 0,t = 0⁺ 驱动已在满幅,所以载波
变量从"对应 y = 0 的那个值"起步。这个反演本身是病态的:α 冻结在 a 时
Φ 的像是 R⁴ 里的 2D 曲面,y = 0 一般不在上面。良定义的对象是**渐近幅值**
—— 让两个强稳定方向坍缩掉,读出轨迹收敛到哪条自由振荡。

之前两次都在猜这个投影(先是线性 ⟨p,·⟩,再是带二次项的 ⟨p,Φ⟩ = 0),而第二
次猜使阈值一致性**变差**(−0.2…−0.4%)。这是投影选错的特征,不是缺项。

三次测量,前两次自己作废,记录在案:
 - wrapA12:ε/ε_c = 0.20…0.65。最大那格 |Z(0)| = 0.76 ρ_g,幅值方程全程强
   非线性,拟合窗内"常数"漂 9%。破绽是拟合出的**线性**系数 4.68e1 对精确
   J = 5.19e1 —— 一个解析精确量错了 10%,整格作废。
 - wrapA1b:降到 ε/ε_c = 0.005…0.08。线性系数对了,但平台相对散布仍是
   8.0e-4 且**正比于 ε**,即 ζ_est 里还留着一个 ε² 项 —— 正是要测的那一项。
   原因是只扣了 Φ 的纯驱动部分(h_0020 α², h_0011 |α|², h_0002 ᾱ²),没扣
   混合项 h_1010 ζα、h_1001 ζᾱ 与纯 ζ 项。这些是振荡的,平台取均值把它们
   平均掉了,所以 R_meas 只有 R_pred 的 2%:测到的是振荡的抵消,不是底下
   的常数。
 - wrapA1c(采信):把整条级数一起反演(逐次迭代,含全部 deg ≤ 3 项),自由
   部分按 log ζ_est − λt = log Z0 + μt 拟合(μ 吸收 c1/c_x 引起的幅值相关
   失谐)。平台残差 8.0e-4 → **2.2e-7**(降 3600 倍)。

结果:

    线性核对   |Z0|/ε = 5.1939792e+01  vs  J = 5.1939096e+01   (+0.00134%)
    R_meas(ε→0) = 1.281e+02 @ +2.518 rad
    R_pred      = 1.217e+03 @ +0.517 rad
    比值 0.105,相位差 +2.000 rad

而且 R_meas 本身正比于 ε(877 → 12783,跨 16 倍),即 Z0 − Z_lin ∝ ε³。

结论:**投入冲击在驱动幅值上是线性的**,ε² 项实质为零(外推截距只有
⟨p,Φ⟩=0 预测的 10.5%,且相位差 2 rad,不是同一个对象)。⟨p,Φ⟩ = 0 反演
不是正确的投影。折算到实际阈值 ε_c:真实二次贡献 0.043%,而之前加上去的
那一项是 0.41% —— 与"加了之后变差 0.2…0.4%"逐位吻合。

所以 A1 的处置是**删掉二次冲击项**,保留线性冲击。这也解释了旧的
"等时线 vs Φ-反演"疑问:两者的二阶修正相消,渐近幅值就是线性投影。

5. A3 GFM 临界性 —— M4 的负斜率是条件数假象,五格全部超临界
                                          [scripts/wrapA34.py, wrapA3b.py]
================================================================================

判据无自由常数:在坐标 z = ⟨p, x − x_eq⟩ 下 ρ' = −αρ + Re c1 ρ³,所以
D(ρ) := −d ln ρ/dt = α − Re c1 ρ²,D 对 ρ² 的斜率就是 −Re c1。负斜率
⇔ Re c1 > 0 ⇔ 亚临界。

解析 Re c1(Kuznetsov g21,Pref = 0.5):

    M1 −3.127187e-03   M2 −4.597481e-03   M3 −1.300246e-03
    M4 −1.223471e-02   M5 −4.606655e-03

五格全负 = 五格全超临界。实测斜率五格全正,符号全部相符。所以上一轮
"M4 负斜率与'GFM 普遍超临界'矛盾"是**测量的问题不是理论的问题**,
"GFM 普遍超临界"在这五格上成立。

M4 为什么会测错,值得记下来:α = 1.963 而 w0 = 12.776,自由振荡每周期衰
e^{−0.96},三周期拟合窗内幅值掉 20 倍,实测 D 只在
1.96500…1.99926 之间变(0.17%),"窗中心的 ρ"这个标签毫无意义。回归在拟合
噪声 —— 这一轮给出量级偏大 2.4 倍,上一轮给出符号翻转。是条件数,不是
临界性。

================================================================================

符号定了以后量级怎么都对不上:M1 极限环半径 +31.7%、M5 −24.5%(纹波 0.56)、
M2 短窗斜率**符号翻转**、M3 +155%。全部同一个错:Re c1 是绕 **Hopf 点**展开

D = D_H(1−η)。超临界 + 不稳定平衡 ⇒ 稳定极限环,半径无拟合:

    ρ_LC = sqrt(α / Re c1),  α = −Re λ < 0,Re c1 < 0

    格   Hopf 处 D      Re c1        η=0.02   η=0.04   η=0.08
    M2   1.5485e-1   −4.585e-3      −0.29%   −0.59%   −1.21%
    M3   1.5768e-2   −1.298e-3      −0.12%   −0.40%      —
    M4   2.7052e-1   −1.180e-2      +0.05%   +0.09%   +0.12%
    M5   7.6924e-2   −4.678e-3      −0.22%   −0.44%      —
    M1   —— 在 D 上 [1e-5, 50 D0] 区间内无 Hopf,跳过

三个 η 同时检 **常数与标度**:半径必须按 sqrt(α) 走,η 减半则半径缩 sqrt2。
实测比值 1.4139 / 1.4142 / 1.4174 / 1.4182 / 1.4185 / 1.4232 对 1.4142。
标度这一条是巧合伪造不了的。

M4 尤其值得对照:同一个格,在工作点上量给出 +21.8%(且上一会话给出符号

9. 慢升协议没有锐阈值 —— 这是结构性的,不是协议没调好
                                    [scripts/noise1b.py → noise1d/1e.py]
================================================================================

慢升协议的判据是"守卫消失",即 α_eff = 0,没有踢击所以看似毫无近似。
第一次检验的方式是延长斜坡(以为 −5…−6% 的残差是非绝热),结果朝**反方向**
走:R = 5 → −6.19%,R = 20 → −8.22%,R = 80 → −10.07%。斜坡越长,实测阈值
越高,离预测越远。非绝热做不出这个方向,而这个符号说明了是什么在起作用。

慢升时状态骑在受迫轨道上,规范形坐标里那就是 ζ = 0 **精确**。精确在 ζ = 0
上的状态无论守卫多小都不会逃逸;逃逸需要残余激励,而唯一供给残余的就是
斜坡本身。斜坡越长越绝热,残余越小,于是需要更大的驱动 —— 正是观察到的
方向。所以**斜坡长度控制的是残余,不是误差**。

真正的限制不是换协议能修的。逃逸率随守卫一起消失:λ_u = 2α_eff → 0,所以
逃逸时间在判据所指的那一点**发散**。任何有限观测窗给出的阈值都高于
α_eff = 0,高多少由窗长而非物理决定。闭式给出的守卫与速率:

    ε/ε*    α_eff        ρ_g        λ_u=2α_eff     1/λ_u
    0.990   1.993e-3   1.269e-3     3.986e-3      251 s
    0.995   9.990e-4   8.986e-4     1.998e-3      501 s
    0.999   2.002e-4   4.023e-4     4.004e-4     2497 s

改扫**保持时长**(斜坡固定 R=20),实测阈值单调降向 ε*:

    hold =  100 s  →  +26.838%
    hold =  300 s  →   +8.958%   (drift −14.10%)
    hold = 1000 s  →   +2.432%   (drift −6.00%)

每次把保持时长放大 ~3 倍,偏差就掉到约三分之一——正是 λ_u ∝ α_eff 而
α_eff 在 ε* 附近线性趋零所要求的对数逼近速率。方向、量级、收敛速率三者
都与"逃逸时间发散"一致。结论:**慢升判据是一个只能对数逼近、
永远达不到的极限点**,与突发投入的观测窗偏差同构,但那个是可以消除的、
这个是不能的。报这类阈值必须同时报窗长。

11. 多音格的残差 —— 三个候选已排除,仍开放
                              [scripts/noise1b.py, noise1c.py, noise1f.py]
================================================================================

双音格是 −0.65…+0.07%,多音格是 ±1…4%,量级差一个数量级,必须解释。

**候选一:拍频。** 不可通约音之间的交叉指标 D − λ = i(ω_j − ω_k) 非共振,
但只被 |ω_j − ω_k| 压制,相对效应 ~ α/|Δω|,所以固定频带与总功率、扫音数 N
应给出误差 ~ αN/BW(跨 16 倍)。实测 N=2/4/8/16/32:
+0.31 / +3.08 / −3.80 / +7.59 / −2.71%。**无趋势,排除。**

**候选二:频带位置。** Re c_x 是半宽 α 的共振,峰值对 0.9ω₀ 处差 1650 倍;
落在共振里的音会破坏"驱动非共振"这个前提(整个战役的单音格一律用
r = 0.90 / 0.92 从不用 1.00,正是为此)。实测把频带整个放到离共振
39–65 α 处:仍是 ±1…4%。**作为"±4% 的成因"排除**——但它解释了另一件事,
见下。

**候选三:展开参数。** 随机相位近抵消时相量和小,阈值 ε 必须变大,而侵蚀
∝ ε² 正是整个构造的展开参数(战役已有的适用域判据 |Re c_x|a²/α ≲ 1)。
在**实测阈值**上逐格算侵蚀/α:范围 0.171–0.844,与 |误差| 的相关系数
r = **+0.196**。**排除。**

**候选四:早期侵蚀。** 预测用的是驱动包络平方的**长时均值**,但逃逸(若发生)
发生在投入后几个包络时间内——自由部分按 e^{−α_eff t} 衰减,守卫只需在早期
被越过。单音时这个区分是空的(|α(t)|² 恒定);多音时不是,交叉项只在远长于
2π/|ω_j−ω_k| 的时间上才平均掉,而 0.70–0.80 带 N=4 的最慢拍周期是 5.8 s,
对包络时间 1/α = 10 s。于是定义窗口均值比
    R_T = ⟨|α(t)|²⟩_[0,T] / Σ|a_k|²,  T = 1/α
逐格用 R_T 缩放侵蚀重算(17 格):平均 |误差| 2.862% → 2.099%,17 格中 11 格
改善,但最大误差从 7.59% 涨到 7.65%,且多格符号翻转。

**这条否定证据本身有信息量**:R_T 在这些格上摆动 0.4461–1.2873(近 3 倍),
而实测残差只有 ±4%。若早期侵蚀真按 R_T 的量级起作用,残差本该比 ±4% 大
得多。所以阈值对**侵蚀发生的时刻**并不敏感,残差不在那里。**候选四排除。**

**候选五:a⁴ 项的多音形式。** 代码对同一类的两个五阶项做了两件不同的事:
c_x 与 c_xx 是驱动幅值的**二次**式,逐音求和与用总量等价(都对);c_a4 是
**四次**式,两种写法差一个 N 因子,只能有一个对。退化极限定判:两音并成一个
振幅 a₁+a₂ 时必须还原成 c_a4|a₁+a₂|⁴,展开后所有 Re(a₁ā₂) 项在不可通约时
振荡掉,剩下 (|a₁|²+|a₂|²)²,即交叉系数是纯系数的两倍,N 音下整项塌缩为
Re c_a4 (Σ|a_k|²)²。**这个推导是对的,但它不是残差**:实测表明 a⁴ 项在
15/17 格上占 α 不到 1%(0.006%…0.98%),三种写法给出的预测在小数点后两位
相同;而残差在 a⁴ 项占 0.006% 的格上(−3.80%)与占 13.3% 的格上(+3.22%)
一样大。**排除。**(附带说明 c_a4 当初为何没被这一条抓到:验证它的单音 V 格
阈值 1.19e-4 处该项只占 α 的 0.044%,不可测——它是在自己不起作用的区域被
验证的,然后被用在了起作用的区域。)

**候选六:稀有事件 / 观测窗。** 准周期驱动的受迫轨道永不重复,拍频使守卫
呼吸,逃逸原则上可以发生在任何一次罕见的音相位对齐上——若如此,多音"阈值"
就是"窗内某处逃逸"的窗依赖量,应随窗长单调下移。实测(0.85–0.95 s7 N=8):
250/500/1000/2000 周期给 7.244575 / 7.243403 / 7.243381 / 7.243403 e−5,
drift −0.0162% / −0.0003% / +0.0003%。**窗口收敛得和单音格一样锐,排除。**
残差是真实的预测误差,不是测量假象。

**闭合:错的不是系数,是比较的形状。**

六个候选排除之后剩下的不是"哪个系数不准",而是判据本身的形状。单音时约化
方程平均后是**自治**的:|α(t)|² = |a|² 恒定,守卫固定在 ρ_g,自由部分单调
衰减,逃逸在 t=0 一次性由 |Z(0)| > ρ_g 决定——一个标量比较精确正确。

N 个不可通约音时这句话没有一个字成立。驱动包络平方

    |α_tot(t)|² = Σ_{j,k} a_j ā_k e^{i(ω_j−ω_k)t}

的均值是 Σ|a_k|²(判据用的就是它),但涨落部分在任何有限时段上都不平均掉。
于是约化方程是**非自治**的

    ζ̇ = λζ + c₁ζ|ζ|² + [Σ_{j,k} c_x^{jk} a_j ā_k e^{i(ω_j−ω_k)t}] ζ

守卫在呼吸,自由部分的衰减被调制,逃逸判据是

    max_t [ |ζ(t)| / ρ_g(t) ] > 1

而不是 t=0 处两个数的比较。这个差别**相位相关**(取决于拍相对投入时刻落在
哪里)、**符号随机**(拍可以帮忙也可以帮倒忙)、**与 N 无关**——正是残差的
三个签名,而六个已排除候选没有一个具备。

直接积分那一个复 ODE 检验(ζ(0) 取线性冲击,已验到 +0.00134%;交叉系数取
窄带近似 c_x^{jk} = (Re c_x(ω_j)+Re c_x(ω_k))/2,对角线上精确),17 格:

7. GFM 侧的闭式 —— 准静态带闭合,共振带结构性开放
                                   [scripts/gfmclose.py → gfmclose2.py]
================================================================================

前提先确认再动手。五格 VSM 的解析 Re c1 全为负(M1 −3.13e-3、M2 −4.60e-3、
M3 −1.30e-3、M4 −1.22e-2、M5 −4.61e-3)= 全部超临界 = 附近根本没有不稳定
极限环。GFL 那套"守卫被侵蚀"的机器在这里没有作用对象,必须换掉而不是移植。
换成的对象是吸引域边界 = P(δ) 上支鞍点的稳定流形,机制是 B3。

第一版(gfmclose.py)只写了状态的运动:

    eps_lin = <n, x_s − x_0> / |<n,H>|,  H = (i w_p I − A_0)^{-1} f_u

在 M2/Xg=0.5/90% 格上给出 +292%(w_p=0.1w0)…−32%(w_p=3w0)。同时测的
"真实盆距"eps_sep 与 eps_lin 处处差几个百分点,所以**几何是对的,判据是
错的**。错在哪由低频行直接读出:w_p=0.1w0 的实测 1.096e-1 落在准静态折叠
值 eps_qs=9.94e-2 上,不在位移值上。慢驱动不是把状态推到固定边界上,是**把
边界拖过来迎接状态**——鞍点也是瞬时驱动的函数,判据只用了相对运动的一半。

两半同形。状态按 H 响应,鞍点按 H_s = (i w_p I − A_s)^{-1} f_u(x_s) 响应,
闭合间隙的只有二者之差,于是定义相对趋近传递函数

    s(w) = <n, H(w) − H_s(w)> ,   s_0 = s(0) = <n, −A_0^{-1}f_u + A_s^{-1}f_u>

两个极限自带:w→0 边界完全跟随驱动;w→∞ 边界完全跟不上,s → <n,H>。

还剩一件线性化给不了的。折叠处间隙按平方根闭合,G(u) ~ C sqrt(u_f − u),
从 u=0 线性外推落在约 2 u_f 上 —— 无论传递函数多精确都差约一倍。所以静态
那一半取精确静态问题的解,频率依赖交给传递函数:

    eps_uni(w_p) = eps_qs · s_0 / |s(w_p)|

w→0 极限按构造精确;s_0/|s| 是纯比值,n 的归一化自动约掉,零拟合。

**平方根结构的定量确认**:四格的 d_geom/s_0 对 eps_qs 之比分别为
2.1819 / 2.1757 / 2.5364 / 2.1703,与平方根折叠预测的约 2 相符。这是"为什么
不能全线性化"的独立证据,不是事后解释。

四格实测(M2/M3 × Xg 0.3/0.5,负载 75%/90%),eps_uni 误差:

    w_p/w0   A(M2 .5 90%)  B(M3 .5 90%)  C(M2 .3 75%)  D(M3 .3 90%)
     0.05      −4.75%        −2.58%        −3.51%        −2.15%
     0.10      −9.10%        −5.16%        −6.87%        −4.28%

 (a) **准静态带 w_p ≲ 0.1 w0 闭合**,四格 −2.15…−9.10%。该带内 eps_qs 本身
     (完全无动力学)就是可用的工程界,四格在 w_p=0.05w0 处 −2.15…−4.75%。

8. 随机驱动的 Kramers 支 —— 谱不能既算扩散又算侵蚀
                        [scripts/noise2.py → noise2b/2c.py → noise3.py + fit]
================================================================================

问题的提法先摆正。确定性驱动给的是阈值(二值);随机驱动**没有阈值**——任何
噪声强度最终都会越过守卫,问题从"是否逃逸"变成"多久逃逸"。这是同一几何
骨架上把叶子从阈值换成速率,不是第六个要素。

推导(全部用已有量,零新拟合)。加性白噪 ⟨u(t)u(t')⟩ = σ²δ(t−t'):

    单边 PSD        S_u = σ²/π
    包络扩散        D̃ = |g|²σ²/4,  g = ⟨p,f_u⟩
    势垒            ΔU = α_eff²/(4 Re c1)
    Kramers         ln T = ΔU/D̃ + const = α_eff²/(Re c1|g|²σ²) + const

**三次自我修正,都记在案:**

(1) Euler–Maruyama 不够。dt=4e-4 给 T=14.08s,dt=2e-4 给 26.76s(同种子)。
    这不是选步长不当,是机理本身:T 对势垒/噪声比是指数敏感的(X~3.4 时 D̃
    差 10% 使 T 差 34%),任何"等效噪声"型离散误差都被 exp(X) 放大。换成
    Heun(加性噪声下无 Itô 修正、无 Milstein 项,故弱二阶)+ 向量化系综
    (M 条实现同时推进,200 条的代价接近 1 条)。

(2) 全系统够不到渐近区。实测前因子 T0 ≈ 42 s ≈ 4/α,所以要把 T 压进可跑
    窗口就被迫取 X ≲ 1,而 X ≲ 1 恰恰是 Kramers 渐近(势垒 ≫ 噪声)**不**
    成立的地方。X=0.50 处实测 std/mean = 0.675 —— 真正的速率过程首通时间
    是指数分布(std/mean → 1),0.675 就是"几乎无势垒"的签名。在那里量斜率
    等于量渡越区然后叫它渐近。**所以把命题一分为二**:
      (I) 4 态系统是否服从 2D 包络 SDE —— 在全系统跑得动的 X~0.2–1 区间比
          对(逃逸时间**分布**,不只是均值);
      (II) 该 2D SDE 是否服从 ln T = X + const —— 便宜地推到 X~2.2+
          (包络方程把载波转掉后只剩 α_eff ~ 0.05 与 Re c1ρ² ~ 0.1 两个速率,
          dt 从 5e-5 放宽到 1e-3)。
    (I) 实测:X=0.187 与 0.501 两点的 T_full/T_reduced = **2.216 / 2.168**,
    **比值恒定** —— 若约化把指数弄错,比值会随 X 指数发散;恒定比值说明
    指数对、前因子差 2.2 倍(逃逸面定义不同:约化取 |Z|>3ρ_g,全系统取
    θ/Vdc 盒)。

(3) 前因子不是常数,不能当截距拟合。二维旋转对称势、圆形势垒,径向
    flux-over-population 给出
        T = sqrt(π D̃ Re c1)/α_eff² · exp(X)
    ⟹ **ln T − ½ln D̃ + 2 ln α_eff = X + const** 才是斜率必须为 1 的量。
    (原始 ln T 对 X 的分段斜率 1.257/0.875/0.779 穿过 1 继续下行;补上
    前因子后是 3.956/2.016/1.395,**朝 1 单调收敛** —— 只有后者有极限可收。)

**接下来我犯了一个错,并在同一轮里抓住了它。记全过程。**

补上前因子后,先用当时手上的四个点(X = 0.187…1.528)拟合:

    势垒用 α_eff(整条谱都算侵蚀):斜率 2.115,rms 0.253
    势垒用 α    (完全不算侵蚀):斜率 0.978,rms 0.040

拟合偏向"没有侵蚀",而按 ∫Re c_x dω 算的侵蚀在那段扫描里是 α 的 29–64%。
我据此推出一个"机理":Re c_x 是半宽 α 的共振,积分由 |ω−ω₀| ≲ α 支配,而
正是这段谱在供给包络扩散 D̃,所以**近共振的谱被数了两次**,应该从侵蚀积分
里排除。扫描排除带宽 K 后斜率确实在 K ≈ 3–5 处过 1,K 是 O(1),看起来自洽,
而且和多音格"越靠近共振误差越大"的独立观察对得上。**这一条已经写进
README、判定树与本文件并推送。**

**它是错的。** 把 X 推到 4.482(七个点)并且**把拟合限制在渐近区**之后:

    拟合窗      K=0(全侵蚀)   K=1     K=3     K=10    K=∞(无侵蚀)
    X > 0.0     1.3505        1.1469  0.9581  0.8780  0.8493
    X > 0.9     **0.9898**    0.9705  0.9065  0.8780  0.8493
    X > 1.4     0.9520        0.9247  0.8734  0.8466  0.8493
    X > 2.0     0.9520        0.9020  0.8510  0.8273  0.8099

一旦把 X < 1 的点剔掉,**K = 0 给出斜率 0.9898**(rms 0.051),而排除得越多
斜率越差,单调。也就是说:

    完整的谱积分侵蚀是对的,不存在双重计数,不需要分带。

先前那个"真结果"完全来自把 X < 1 的点放进回归——而 X ≲ 1 正是 Kramers
渐近不成立的地方。**这恰恰是我在两步之前刚刚诊断过的同一个错误**:我把
"不能在非渐近区量斜率"这条纪律用在了**仿真设计**上(所以才把命题一分为二),
却没有把它用在**回归窗口**上。教训是纪律要贯穿到读数那一步,不是只到产生
数据那一步。

**更正后的结论**:

    ln T − ½ln D̃ + 2 ln α_eff = X + const,  α_eff 用完整谱积分
    渐近区(X > 0.9,四点)实测斜率 **0.9898**,rms 0.051
    去掉侵蚀项则为 0.8493 —— 侵蚀项确实在,且量值正确

std/mean 随 X 单调上行(0.589 → 0.646 → 0.668 → 0.768 → 0.838 → 0.906 →
0.920),朝速率过程该有的 1 收敛。这条本身就是"X < 1 的点不在渐近区"的独立
证据——它当时就在日志里,我没有用它来筛回归窗口。

**与多音格的关系要切断,不要合并。** 多音格"最近音越靠近 ω₀ 误差越大"
(0.65α 处 +30.7% → 38–65α 处 ±1–4%)仍然成立,但它说的是**双载波展开在
近共振处失效**(|H| ~ 1/α,near-identity 变换趋于奇异),那是适用域问题;
它**不**说明侵蚀积分要分带。两件事我先前错误地并成了一条,现分开。

     8      4.678     3.451159e5    3.372975e5    1.0232     −2.19%
    32      1.041     3.371234e5    3.372975e5    0.9995     −3.01%
   128      0.257     3.371596e5    3.372975e5    0.9996     −1.83%

音间距降到 ~α 时离散和与谱积分已差 0.05%,再加密 4 倍不再变化(0.9995 →
0.9996)。离共振处 c_x 随 ω 变化平缓,所以连续极限来得很快。

而**实测误差在这三格上没有随之收敛**(−2.19 / −3.01 / −1.83%),这是第 11 节
那个开放项的又一个独立证据:侵蚀项本身在两种写法之间只差万分之四,残差
不可能出在它上面。

13. 本轮结论一览 / 仍开放
================================================================================

**闭合(附精度)**
  1. 五阶闭式三通道覆盖:V +0.03% / P +0.03% / Q +0.06%(Q 的 +0.57% 是
     驱动符号错绑,不是理论误差;P 的乘性份额恒为零,已由符号审计判定)
  2. 投入踢击对驱动幅值是线性的:+0.00134%;二次踢击项应删去
  3. 五阶逃逸率 λ_u = 2α_eff + 2Re c2 ρ_g⁴:对精确 Floquet +0.01…+0.15%
  4. 多音侵蚀是谱上的标量和(三次阶无交叉),冲击是相量和:双音 −0.65…+0.07%,
     反相格是判决性证据;连续极限与离散和差 0.05%
  5. Re c_x(ω) 会变号——次谐波带的驱动加固守卫
  6. GFM 全部五格超临界;Re c1 量级在 Hopf 点复测 −1.21…+0.12%,含 sqrt(α) 标度
  7. GFM 盆边界闭式 ε_qs·s₀/|s(ω_p)| 在准静态带 −2.15…−9.10%
  8. 随机驱动:判决类型从阈值变速率;Kramers 指数与前因子均导出,分带后
     斜率 1.023;约化的验证靠 T_full/T_red 比值恒定
  9. 传感器不变性:κ_g 跨 100 倍读数只差 0.17 个百分点;盲方向无输入
 10. 观测窗逐格表;慢升协议是极限点不是阈值(hold 100/300/1000 s 给
     +26.84/+8.96/+2.43%)
 11. 多音判据的适用条件:每个音须离 ω₀ 至少 5–10 α

**仍开放**
  A. 多音格远离共振时的 ±1…4% 残差。已排除:拍频、频带位置、展开参数。
     与相位实现有关。按战役标准(>1% 须机理闭合)未闭合。
  B. GFM 共振带(0.3–0.9 ω₀)的闭式。结构性开放,不是精度问题——阈值处
     受迫位移达间隙的 24–82%,任何局部展开都留 O(1) 误差。正确对象是沿
     边界轨道的 Melnikov 型伴随积分。
  C. GFM M2 格在 160→320 周期出现 −10.36% 的窗口**跳变**(非漂移),
     提示在该区间打开了另一条更慢的逃逸通道,未追。
  D. Kramers 支的分带宽度 K 只定到"数个 α"。要定到一位有效数字需把 X
     推到 5 以上,本轮算力不够(全系统前因子 T0 ≈ 4/α 使 X ≳ 1 就跑不动,
     约化模型可以但需另一个量级的机时)。

15. 自查(2026-08-10 第二轮)—— 对上一节刚发布的结论做对照实验

用户要求再自查。以下逐条,其中前两条是**上一节(第 11 节)刚推送的内容里的

--------------------------------------------------------------------------------
15.1 【方法缺陷,已补】多音闭合的对照没做干净

第 11 节的结论"系数没错、比较的形状错了"是从 2.862% → 0.521% 得出的。
但重读两个预测器,它们**不是只差一件事,是差两件**:

    闭式:  guard_root(α_eff, c1 + c_xx a2t, c2)  ← 五阶项在
           |Z(0)| > ρ_g                          ← 拍频不在
    约化:  ζ̇ = −αζ + c1ζ|ζ|² + E(t)ζ            ← 拍频在,五阶项不在

所以改善可能来自拍频,也可能来自"丢掉 c2/c_xx/c_a4 恰好有利"。把它归因于
拍频**当时没有挣到**。而且有具体的理由怀疑:约化 ODE 最差的两格恰好就是
五阶含量最高的两格(a⁴/α = 13.3% → +1.54%,9.5% → +1.16%)。

补的对照 A:把 E(t) 换成它的时间均值(常数),其余一切不变。常数 E 时三次
径向方程的精确分界就是 ρ_g,所以这一版**必须**逐位复现闭式。17 格结果:

    最大 |差| = 0.000%   (逐格 ±0.000%)

**对照通过。** 积分方法、逃逸面取法、五阶项的有无都不做功,拍频被隔离出来。
第 11 节的结论**成立**——但它现在才算被证明,而不是当时。

--------------------------------------------------------------------------------
15.2 【归因错误,撤回】剩余 0.5% 的去处不是"交叉系数的窄带近似"

第 11 节写:"剩余 ≤1.54% 有具名去处:交叉系数用了窄带近似……"。两个对照
表明这句话**只对一半,而且当时是断言不是测量**。

对照 C(换三种合理的交叉系数插值:算术平均 / 几何平均 / 中点频率):

    逐格离散度最大 0.865%,典型 <0.2%

所以交叉系数的取法**确实**贡献了残差的一部分,但撑不起 0.5% 的全部,更撑不
起 1.54% 的最大值。

对照 B(把五阶项加进约化 ODE,使两个预测器只差一件事):

    平均 |误差|  闭式 2.862%  |  约化+五阶 0.536%  |  约化(仅拍频) 0.521%
    最大 |误差|  闭式 7.590%  |  约化+五阶 1.285%  |  约化(仅拍频) 1.541%

五阶含量最高的两格确实改善(+1.54% → +1.03%,+1.16% → +0.87%),但多个低
五阶含量的格反而变差(−0.30% → −1.29%,−0.03% → −0.97%),平均持平。

**这个对照本身不干净,必须说明**:我加的五阶分支里,c_xx 用的是**时间平均**
的 a2t,c_a4 用的是**逐音**的 Σa_k⁴——前者与非自治处理不一致,后者已被
noise1h 的退化极限论证判定为错误的多音形式。**正确的做法是让五阶项也用
瞬时的 |α_tot(t)|²**,那没有实现。所以**对照 B 是不确定的**,不能据它下
结论。

**更正后的表述**:剩余 0.5%(最大 1.5%)有两个具名贡献者——交叉系数的
插值(实测离散度 ≤0.87%)与五阶项的非自治多音形式(未实现)。两者都是可
计算对象,但**哪个占主导本轮没有分离出来**。原先"是交叉系数"的说法撤回。

--------------------------------------------------------------------------------
15.3 【过度精确,收窄】Kramers 斜率 0.9898 报了四位有效数字

那是 X > 0.9 的**四个点**的拟合;把窗口收到 X > 1.4 只剩三个点,斜率变成
0.9520。一个点的进出就是 4% 的摆动。诚实的表述是**"与 1 相符,精度约 5%"**,
不是 0.9898。同理,分带扫描里"K=0 最好"这个排序在 X>0.9 与 X>2.0 两个窗口
上一致(单调),那一条**方向**结论稳;但 K 值本身在三点拟合上分辨不出来。

撤回"谱的双重计数"这件事本身**不受影响**——它的证据是 K=0 随窗口收紧
单调变好、K=∞ 单调变差,是排序不是数值。

--------------------------------------------------------------------------------
15.4 【口径不一致,更正】GFM 准静态带不该叫"闭合"

第 7 节写"准静态带 w_p ≲ 0.1 w0 闭合,四格 −2.15…−9.10%"。按本战役自己
的标准(>1% 必须机理闭合),2–9% **不是闭合**。即使在 w_p = 0.05 w0 处也是
−2.15…−4.75%,仍然 >1%。

正确表述:ε_uni 在 ω→0 极限上**按构造精确**(它就是 ε_qs),在准静态带内
是**目前最好的可用闭式**,但 2–9% 的有限频率残差**未做机理闭合**,与共振带
的结构性开放是两件不同的事(那个是展开失效,这个是没追)。GFM 侧因此有
**两个**开放项而不是一个。

--------------------------------------------------------------------------------
15.5 【断言未验,现已验】传感器的共同偏差确实是提取链

sensor3 报"κ_g 跨 100 倍读数只差 0.17 个百分点(不变性成立),共同偏差
+1.6%/+14% 来自包络提取"。后半句当时是**断言**。现用合成信号验:直接由被
拟合的那条律 ρ̇ = −αρ + Re c1 ρ³ 解析构造 ρ(t),乘载波做成 y(t),过同一条
带通 + Hilbert + 滑窗对数斜率链——信号里零模型误差:

    纯模态,无二模态,无噪声      α +1.82%   斜率 +18.97%
    加二模态(0.30x)             α +2.24%   斜率 +22.80%
    加二模态 + 噪声 1e-3         α +2.16%   斜率 +22.25%
    加二模态 + 噪声 1e-2         α +1.38%   斜率 +17.40%

与实测的 +1.6%/+14% 同量级同符号,**归因成立**(合成略大,差额应是真实格里
的五阶项)。κ_g 不变性这一条本来就靠"跨传感器离散度"而非绝对值,不受影响。

--------------------------------------------------------------------------------
15.6 【表述收紧】判据的锐对象是"积分那条方程",不是 max_t 的比值

第 11 节把多音判据写成 max_t |ζ(t)|/ρ_g(t) > 1。实际实现并且真正锐的对象是
**积分那条非自治约化方程、看轨迹是否逃逸**;max_t 的比值是个便于说的近似
说法(ρ_g(t) 作为"瞬时守卫"本身是准静态概念,守卫响应有自己的 1/α 时标)。
本战役对"锐对象 vs 代理"一向严格,这里也照办:锐对象是方程,不是比值。

--------------------------------------------------------------------------------
15.7 【证据薄,标注】约化对全系统的验证只有两个点

第 8 节用 T_full/T_reduced 在 X=0.187 与 0.501 处的**恒定比值**(2.216 /
2.168)论证"约化把指数弄对了"。那是**两个点**。方向对、逻辑对(指数错会使
比值随 X 指数发散),但两点不足以称为标定。标注为证据薄,不改结论。
