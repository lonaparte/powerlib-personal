1. Q 通道的 +0.57% —— 是驱动变量错绑,不是理论误差   [scripts/mech9.py]
================================================================================

诊断。mech7 的 tensors5 把第五个展开变量硬编码成 V_,mech8 却把这套机器
直接用在 P / Q 通道上。于是无论驱动挂在哪个参数上,乘性(参数)算子永远
是 ∂²f/∂y∂V。

符号审计(在 Hopf 点求值)直接判定:

    u = V : 恒零 = False,  ‖∂²f/∂y∂V‖_max = 5.91192e+03
    u = P : 恒零 = True,   ‖·‖_max = 0.00000e+00
    u = Q : 恒零 = False,  ‖∂²f/∂y∂Q‖_max = 1.18238e+02
    cos∠(V,Q) = +0.01230

两条硬事实:
 (a) P 只经 P/C 进入直流母线平衡,∂f/∂P = e₃/C 与状态无关,所以
     ∂²f/∂y∂P ≡ 0,P 的乘性份额必须精确为零。mech8 打印 −0.02%,那是
     V 张量泄漏进 P 的运行。
 (b) V 与 Q 的混合二阶算子几乎正交(cos = 0.012)。所以 V-绑定的 Q 运行
     连"差一个标度"都不是,它用的是一个方向完全不同的算子。

按通道重建张量后(nf5drv.py 把驱动符号做成参数)重跑 G1 margin 0.10、
r = 0.90,对照 3000 周期收敛后的实测阈值:

    通道 |  仅可加   | 可加+乘性 | 乘性份额  | V-绑定(mech8)
    -----+-----------+-----------+-----------+---------------
     V   |  +0.14%   |  +0.03%   |  +0.44%   |  +0.03%
     P   |  +0.03%   |  +0.03%   |  +0.00%   |  +0.04%
     Q   |  +0.56%   |  +0.06%   |  +1.90%   |  +0.57%

P 的乘性增量精确为 +0.000000e+00,与符号审计一致。Q 自己的乘性增量是
+4.334475e+04(占 Re c_x 的 1.90%),V-绑定给出的是 −3.375993e+02 —— 量级
和符号都错。

结论:五阶闭式在三个通道上都是 ≤ +0.06%。上一轮"≤0.12% 只在 V/P 成立"
的撤回**再撤回**:它在 Q 上同样成立,之前的 +0.57% 是实现层的绑定 bug。

窗口偏差(1000 → 3000 周期)在三个通道上都是 +0.00%,所以这些数字不含
观测窗人为量。


================================================================================
2. 随机 / 宽带驱动 —— 侵蚀是谱上的标量和   [scripts/noise1.py, noise1b.py]
================================================================================

推导。把驱动写成多载波 u(t) = Σ_k (a_k e^{i w_k t} + c.c.)。约化 ζ 方程的
共振条件是

    D_π = j λ + k λ̄ + Σ_k (l_k − m_k) i w_k = λ

对不可通约的 w_k 只剩 j = k+1 且每个 k 满足 l_k = m_k。两条结论,都是免费的:

 (E1) 三次阶没有交叉侵蚀。指数 (l₁−m₁, l₂−m₂) = (+1, −1) 给出
      D − λ = i(w₁−w₂) ≠ 0,非共振。所以
          α_eff = α − Σ_k Re c_x(w_k) |a_k|²
      用的还是同一个 c_x(w),逐音求值。连续谱极限(单边 PSD S_u,
      ⟨u²⟩ = ∫S_u dw):
          α_eff = α − (1/2) ∫ Re c_x(w) S_u(w) dw
 (E2) 投入冲击是**相量和**不是标量和,因为各音共用同一通道方向 f_u,
      只有复分母不同:
          Z(0) = Σ_k 2 a_k λ ⟨p,f_u⟩ / (w_k² + λ²)

双音实测(G1 margin 0.10,V 通道,突发投入):

    w₁=0.90 w₂=0.90/φ  1:1        −0.13%    侵蚀分配 100.1 / −0.1
    w₁=0.90 w₂=0.90/φ  1:0.5      −0.01%                100.0 / −0.0
    w₁=0.90 w₂=1.30    1:1        −0.65%                 68.5 / 31.5
    w₁=0.90 w₂=0.45    1:1        +0.07%                101.8 / −1.8
    w₁=0.90 w₂=0.90/φ  反相       −0.21%                100.1 / −0.1

反相那一格是相量和的直接证据:同样的两个音,只把第二个音的相位翻 π,
阈值从 1.044e-4 抬到 1.345e-4(+29%),预测 −0.21%。标量和无法产生这个差别。

顺带一个不是设计出来的发现:Re c_x(w) **会变号**。w₂ = 0.90/φ ≈ 0.556 w₀
和 w₂ = 0.45 w₀ 两格的侵蚀分配是 −0.1% 和 −1.8%,即这些频率的驱动
**加固**守卫而不是侵蚀它。所以"任何扰动都削裕度"是错的,次谐波带的
驱动在这套机理下是稳定化的。

多音格的残差与其机理(noise1b)见第 6 节。

3. A2 五阶逃逸率 —— 闭式把 +0.82% 收到 +0.15%   [scripts/wrapA12.py]
================================================================================

径向方程 ρ' = −α_eff ρ + c1_eff ρ³ + Re c2 ρ⁵ 在守卫处的导数,用
α_eff = c1_eff ρ_g² + Re c2 ρ_g⁴ 消去 ρ_g:

    λ_u = −α_eff + 3 c1_eff ρ_g² + 5 Re c2 ρ_g⁴
        = 2 c1_eff ρ_g² + 4 Re c2 ρ_g⁴
        = 2 α_eff + 2 Re c2 ρ_g⁴          (三次极限即 λ_u = 2α)

对照**精确 Floquet 指数**(无驱动不稳定极限环,(点,周期) 系统上牛顿求解 +
单值矩阵),四个裕度:

    α     精确 λ_u      2α (三次)          五阶闭式
    0.05  0.09982328    0.10000024 +0.18%  0.09983124 +0.01%
    0.10  0.19924993    0.20000024 +0.38%  0.19932847 +0.04%
    0.15  0.29824131    0.30000009 +0.59%  0.29849796 +0.09%
    0.20  0.39673973    0.39999981 +0.82%  0.39734572 +0.15%

第二乘子在四格上都是 1.000000(平凡乘子),所以环确实找对了。

4. A1 投入冲击 —— 冲击是线性的,二次修正本来就不该加
                                     [scripts/wrapA12.py → wrapA1b.py → wrapA1c.py]
================================================================================

问题的提法。t = 0⁻ 系统在无驱动平衡点 y = 0,t = 0⁺ 驱动已在满幅,所以载波
变量从"对应 y = 0 的那个值"起步。这个反演本身是病态的:α 冻结在 a 时
Φ 的像是 R⁴ 里的 2D 曲面,y = 0 一般不在上面。良定义的对象是**渐近幅值**
—— 让两个强稳定方向坍缩掉,读出轨迹收敛到哪条自由振荡。

之前两次都在猜这个投影(先是线性 ⟨p,·⟩,再是带二次项的 ⟨p,Φ⟩ = 0),而第二
次猜使阈值一致性**变差**(−0.2…−0.4%)。这是投影选错的特征,不是缺项。

三次测量,前两次自己作废,记录在案:
 - wrapA12:ε/ε_c = 0.20…0.65。最大那格 |Z(0)| = 0.76 ρ_g,幅值方程全程强
   非线性,拟合窗内"常数"漂 9%。破绽是拟合出的**线性**系数 4.68e1 对精确
   J = 5.19e1 —— 一个解析精确量错了 10%,整格作废。
 - wrapA1b:降到 ε/ε_c = 0.005…0.08。线性系数对了,但平台相对散布仍是
   8.0e-4 且**正比于 ε**,即 ζ_est 里还留着一个 ε² 项 —— 正是要测的那一项。
   原因是只扣了 Φ 的纯驱动部分(h_0020 α², h_0011 |α|², h_0002 ᾱ²),没扣
   混合项 h_1010 ζα、h_1001 ζᾱ 与纯 ζ 项。这些是振荡的,平台取均值把它们
   平均掉了,所以 R_meas 只有 R_pred 的 2%:测到的是振荡的抵消,不是底下
   的常数。
 - wrapA1c(采信):把整条级数一起反演(逐次迭代,含全部 deg ≤ 3 项),自由
   部分按 log ζ_est − λt = log Z0 + μt 拟合(μ 吸收 c1/c_x 引起的幅值相关
   失谐)。平台残差 8.0e-4 → **2.2e-7**(降 3600 倍)。

结果:

    线性核对   |Z0|/ε = 5.1939792e+01  vs  J = 5.1939096e+01   (+0.00134%)
    R_meas(ε→0) = 1.281e+02 @ +2.518 rad
    R_pred      = 1.217e+03 @ +0.517 rad
    比值 0.105,相位差 +2.000 rad

而且 R_meas 本身正比于 ε(877 → 12783,跨 16 倍),即 Z0 − Z_lin ∝ ε³。

结论:**投入冲击在驱动幅值上是线性的**,ε² 项实质为零(外推截距只有
⟨p,Φ⟩=0 预测的 10.5%,且相位差 2 rad,不是同一个对象)。⟨p,Φ⟩ = 0 反演
不是正确的投影。折算到实际阈值 ε_c:真实二次贡献 0.043%,而之前加上去的
那一项是 0.41% —— 与"加了之后变差 0.2…0.4%"逐位吻合。

所以 A1 的处置是**删掉二次冲击项**,保留线性冲击。这也解释了旧的
"等时线 vs Φ-反演"疑问:两者的二阶修正相消,渐近幅值就是线性投影。

5. A3 GFM 临界性 —— M4 的负斜率是条件数假象,五格全部超临界
                                          [scripts/wrapA34.py, wrapA3b.py]
================================================================================

判据无自由常数:在坐标 z = ⟨p, x − x_eq⟩ 下 ρ' = −αρ + Re c1 ρ³,所以
D(ρ) := −d ln ρ/dt = α − Re c1 ρ²,D 对 ρ² 的斜率就是 −Re c1。负斜率
⇔ Re c1 > 0 ⇔ 亚临界。

解析 Re c1(Kuznetsov g21,Pref = 0.5):

    M1 −3.127187e-03   M2 −4.597481e-03   M3 −1.300246e-03
    M4 −1.223471e-02   M5 −4.606655e-03

五格全负 = 五格全超临界。实测斜率五格全正,符号全部相符。所以上一轮
"M4 负斜率与'GFM 普遍超临界'矛盾"是**测量的问题不是理论的问题**,
"GFM 普遍超临界"在这五格上成立。

M4 为什么会测错,值得记下来:α = 1.963 而 w0 = 12.776,自由振荡每周期衰
e^{−0.96},三周期拟合窗内幅值掉 20 倍,实测 D 只在
1.96500…1.99926 之间变(0.17%),"窗中心的 ρ"这个标签毫无意义。回归在拟合
噪声 —— 这一轮给出量级偏大 2.4 倍,上一轮给出符号翻转。是条件数,不是
临界性。
