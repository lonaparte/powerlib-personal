一、五阶双载波同调求解
═══════════════════════════════════════════════════════════════════
令 ζ = Z e^{iω₀t}、α = a e^{iω_p t},问题在四个变量 (ζ, ζ̄, α, ᾱ) 上是
**自治多项式**——驱动 ε cos(ω_p t) f_u 恰好等于 f_u(α + ᾱ),是新变量里的
线性项,时间显式依赖被完全吸收:

  ζ̇ = λζ + g(ζ,ζ̄,α,ᾱ),  α̇ = iω_p α,
  y = Φ = Σ_π h_π ζ^j ζ̄^k α^l ᾱ^m

不变性给出逐指标同调方程

  [D_π I − A] h_π = N_π − T_π,  D_π = jλ + kλ̄ + (l−m)iω_p

N 来自场的 Taylor 张量 B…E,T 是输运项 ∂Φ/∂ζ·g + ∂Φ/∂ζ̄·ḡ。
在 Hopf 点 λ = iω₀,于是 **D_π = λ 精确成立当且仅当 π = (j+1, j, l, l)**,
这些就是约化方程里活下来的共振项:

  (2,1,0,0) → c₁      (1,0,1,1) → c_x
  (3,2,0,0) → c₂      (2,1,1,1) → c_xx      (1,0,2,2) → c_a4

(ω_p = 0.9ω₀ 是有理比,但 (j−k−1) + 0.9(l−m) = 0 在 5 阶内只有 l=m 一解,
共振结构安全;代码对每个指标算条件数并报警。)

**三条独立校验**(动手用之前):
  c₁  vs Kuznetsov 公式      相对差 2.4e-08(G1)/ 4.1e-09(idx17)
  c_x vs 上一轮手推的和频/差频/直流表达式  相对差 1.1e-08 / 1.3e-09
  Re c₂ vs 既有五阶同调求解器(nf5)      −4.9588e4 / +21.090,五位吻合
  (Im c₂ 因非共振消去的取法不同而不同;径向方程只用 Re c₂。)

**新系数**(Hopf 点):
  G1:    Re c₂ = −4.9588e+04,Re c_xx = +2.7516e+09,Re c_a4 = +3.3380e+12
  idx17: Re c₂ = +2.1090e+01,Re c_xx = +2.7301e+04,Re c_a4 = +5.5479e+06

于是径向方程在两个幅值上都到五阶:

  ρ̇ = −α_eff ρ + c₁_eff ρ³ + Re c₂ ρ⁵
  α_eff = α − Re c_x |a|² − Re c_a4 |a|⁴
  c₁_eff = Re c₁ + Re c_xx |a|²
  守卫 ρ_g = Re c₂ ρ⁴ + c₁_eff ρ² − α_eff = 0 的正根(**α_eff ≤ 0 时守卫
  不存在,判为逃逸**——这一条第一次实现时漏了,四次方程的第二个正根被
  当成守卫,阈值搜索锁到它上面给出 +785% 的假解,已修正)
  投入踢击 |Z(0)| = εJ,J = |λ||⟨p,f_u⟩|/|ω_p²+λ²|
  逃逸判据 |Z(0)| > ρ_g

**系数在哪算**:同调求解必须在 Hopf 点(工作点上 (2,1,0,0) 的分母是 −2α,
近共振,消去不合法);但 c₁ 与 c_x 各自有在工作点正则的闭式,在工作点求值
等于把它们的领头 α 依赖重求和(mech3 实测值 0.2–0.45 个百分点)。所以:
**c₁、c_x 取工作点,c₂、c_xx、c_a4 取 Hopf 点由 α 承担展开**。

三、最后一项:驱动还是乘性的
═══════════════════════════════════════════════════════════════════
V 格五阶闭式剩 +0.13…+0.16%,idx17 剩 +1.14%。用 **4D Taylor 场逐阶**
(3/4/5 阶,同协议同读出)去查是不是场的截断:

  V 格(α=0.10):精确场 1.186534e-04
    Taylor 3 阶 1.188166e-04  +0.14%
    Taylor 4 阶 1.188198e-04  +0.14%
    Taylor 5 阶 1.188198e-04  +0.14%

**残差完全不随多项式阶下降** —— 那它就不是 Taylor 截断。两次运行的唯一
差别是:精确场把驱动放在参数里(V₀ + ε cos),所以驱动同时**调制** A、B、C;
Taylor 版本(以及此前的双载波约化)只留了加性的 f_u。缺的是**乘性通道**
M₁ = ∂A/∂u、f_uu = ∂²f/∂u²、∂²f/∂y∂u …—— 正是产生参数舌的那个对象,
这里作用在直接强迫问题上。

补法不需要新机器:**把驱动当第五个展开变量**。令 u = α + ᾱ,场按 (y,u)
联合展开 F = Σ_{k,m} (1/(k!m!)) ∂^{k+m}f/∂y^k∂u^m [y^k] u^m;因为 u 本身在
载波变量里是一次的,整套双载波同调求解原样跑,只是张量表从四变量变五变量。
由此自动补上:f_uu 给的 O(a²) 工作点偏移、∂²f/∂y∂u 给的 c_x 参数分量,
以及它们在 c_xx、c_a4 里的五阶伙伴。

校验:c₁ 完全不变(它不含 u 依赖)✓;c_x 的加性部分与手推值 reldiff 1e-8 ✓。

  乘性通道在 Re c_x 中的份额:V 格 +0.44%,idx17 +2.26%

**最终对照(五阶 + 加性 + 乘性,零拟合)**:

  α      实测阈值        仅加性     加性+乘性
 0.05   8.433772e-05    +0.13%     **+0.01%**
 0.10   1.186532e-04    +0.14%     **+0.03%**
 0.15   1.446190e-04    +0.15%     **+0.03%**
 0.20   1.662439e-04    +0.16%     **+0.04%**

→ 闭式阈值现在与数值判据同精度(≤0.12%),且全部由模型量组成:
  λ, q, p, c₁, c_x, c₂, c_xx, c_a4, J —— 没有一个是拟合的。
