一、五阶双载波同调求解
═══════════════════════════════════════════════════════════════════
令 ζ = Z e^{iω₀t}、α = a e^{iω_p t},问题在四个变量 (ζ, ζ̄, α, ᾱ) 上是
**自治多项式**——驱动 ε cos(ω_p t) f_u 恰好等于 f_u(α + ᾱ),是新变量里的
线性项,时间显式依赖被完全吸收:

  ζ̇ = λζ + g(ζ,ζ̄,α,ᾱ),  α̇ = iω_p α,
  y = Φ = Σ_π h_π ζ^j ζ̄^k α^l ᾱ^m

不变性给出逐指标同调方程

  [D_π I − A] h_π = N_π − T_π,  D_π = jλ + kλ̄ + (l−m)iω_p

N 来自场的 Taylor 张量 B…E,T 是输运项 ∂Φ/∂ζ·g + ∂Φ/∂ζ̄·ḡ。
在 Hopf 点 λ = iω₀,于是 **D_π = λ 精确成立当且仅当 π = (j+1, j, l, l)**,
这些就是约化方程里活下来的共振项:

  (2,1,0,0) → c₁      (1,0,1,1) → c_x
  (3,2,0,0) → c₂      (2,1,1,1) → c_xx      (1,0,2,2) → c_a4

(ω_p = 0.9ω₀ 是有理比,但 (j−k−1) + 0.9(l−m) = 0 在 5 阶内只有 l=m 一解,
共振结构安全;代码对每个指标算条件数并报警。)

**三条独立校验**(动手用之前):
  c₁  vs Kuznetsov 公式      相对差 2.4e-08(G1)/ 4.1e-09(idx17)
  c_x vs 上一轮手推的和频/差频/直流表达式  相对差 1.1e-08 / 1.3e-09
  Re c₂ vs 既有五阶同调求解器(nf5)      −4.9588e4 / +21.090,五位吻合
  (Im c₂ 因非共振消去的取法不同而不同;径向方程只用 Re c₂。)

**新系数**(Hopf 点):
  G1:    Re c₂ = −4.9588e+04,Re c_xx = +2.7516e+09,Re c_a4 = +3.3380e+12
  idx17: Re c₂ = +2.1090e+01,Re c_xx = +2.7301e+04,Re c_a4 = +5.5479e+06

于是径向方程在两个幅值上都到五阶:

  ρ̇ = −α_eff ρ + c₁_eff ρ³ + Re c₂ ρ⁵
  α_eff = α − Re c_x |a|² − Re c_a4 |a|⁴
  c₁_eff = Re c₁ + Re c_xx |a|²
  守卫 ρ_g = Re c₂ ρ⁴ + c₁_eff ρ² − α_eff = 0 的正根(**α_eff ≤ 0 时守卫
  不存在,判为逃逸**——这一条第一次实现时漏了,四次方程的第二个正根被
  当成守卫,阈值搜索锁到它上面给出 +785% 的假解,已修正)
  投入踢击 |Z(0)| = εJ,J = |λ||⟨p,f_u⟩|/|ω_p²+λ²|
  逃逸判据 |Z(0)| > ρ_g

**系数在哪算**:同调求解必须在 Hopf 点(工作点上 (2,1,0,0) 的分母是 −2α,
近共振,消去不合法);但 c₁ 与 c_x 各自有在工作点正则的闭式,在工作点求值
等于把它们的领头 α 依赖重求和(mech3 实测值 0.2–0.45 个百分点)。所以:
**c₁、c_x 取工作点,c₂、c_xx、c_a4 取 Hopf 点由 α 承担展开**。

三、最后一项:驱动还是乘性的
═══════════════════════════════════════════════════════════════════
V 格五阶闭式剩 +0.13…+0.16%,idx17 剩 +1.14%。用 **4D Taylor 场逐阶**
(3/4/5 阶,同协议同读出)去查是不是场的截断:

  V 格(α=0.10):精确场 1.186534e-04
    Taylor 3 阶 1.188166e-04  +0.14%
    Taylor 4 阶 1.188198e-04  +0.14%
    Taylor 5 阶 1.188198e-04  +0.14%

**残差完全不随多项式阶下降** —— 那它就不是 Taylor 截断。两次运行的唯一
差别是:精确场把驱动放在参数里(V₀ + ε cos),所以驱动同时**调制** A、B、C;
Taylor 版本(以及此前的双载波约化)只留了加性的 f_u。缺的是**乘性通道**
M₁ = ∂A/∂u、f_uu = ∂²f/∂u²、∂²f/∂y∂u …—— 正是产生参数舌的那个对象,
这里作用在直接强迫问题上。

补法不需要新机器:**把驱动当第五个展开变量**。令 u = α + ᾱ,场按 (y,u)
联合展开 F = Σ_{k,m} (1/(k!m!)) ∂^{k+m}f/∂y^k∂u^m [y^k] u^m;因为 u 本身在
载波变量里是一次的,整套双载波同调求解原样跑,只是张量表从四变量变五变量。
由此自动补上:f_uu 给的 O(a²) 工作点偏移、∂²f/∂y∂u 给的 c_x 参数分量,
以及它们在 c_xx、c_a4 里的五阶伙伴。

校验:c₁ 完全不变(它不含 u 依赖)✓;c_x 的加性部分与手推值 reldiff 1e-8 ✓。

  乘性通道在 Re c_x 中的份额:V 格 +0.44%,idx17 +2.26%

**最终对照(五阶 + 加性 + 乘性,零拟合)**:

  α      实测阈值        仅加性     加性+乘性
 0.05   8.433772e-05    +0.13%     **+0.01%**
 0.10   1.186532e-04    +0.14%     **+0.03%**
 0.15   1.446190e-04    +0.15%     **+0.03%**
 0.20   1.662439e-04    +0.16%     **+0.04%**
 idx17  7.099026e-03    +1.14%     **+0.12%**

→ 闭式阈值现在与数值判据同精度(≤0.12%),且全部由模型量组成:
  λ, q, p, c₁, c_x, c₂, c_xx, c_a4, J —— 没有一个是拟合的。

六、判据在 PCC 可观量里的表述(pccobs / rampwin)
═══════════════════════════════════════════════════════════════════
判据本来写在模态坐标里(|Z| 对 ρ_g)。翻到实际测得到的量:任何 PCC 可观量
g 的摆幅 = 2|Z|·|∇_x g · q|,所以守卫半径直接翻译成"临界摆幅"。频率也在内
——GFL 的频率就是 PLL 输出 θ̇ = kp·v_gq + ki·x_pll,GFM 的 ω 本身是状态。

**到边界时各可观量的摆幅**(0.9× 突加阈值,V 通道,r=0.9,margin 0.10):

  可观量        角度族 G1(5.16 Hz)   直流族 idx2(10.85 Hz)
  |v_pcc|        0.547%                2.186%
  P_pcc          0.464%                7.800%
  |i_pcc|        0.731%                8.292%
  频率           0.032 Hz              0.259 Hz
  V_dc           0.454%                7.130%

  → **到边界时看到的振荡很小**:角度族全部 <1%,频率只有 0.03 Hz。
    "大幅度频率/电流振荡"是越界之后的现象,不是前兆。这就是"无前兆"
    这条性质在可观量里的样子。
  → 两族的签名(绝对摆幅比):dP/dV = 1.56(角度族)vs 5.93(直流族);
    百分比摆幅比 |i|%/|v|% = 1.34 vs 3.79。单看这一个比值即可分族。
  → 已知限制:PCC 上 P 通道与 Q 通道几乎简并(|v| 相位 117.2° vs 118.8°),

  → 临界 PCC 状态与驱动通道近乎无关(pccmap:三个通道给 0.53–0.55% 电压
    摆幅),所以判据可以直接写成"PCC 电压摆幅超过 X% 即触边界"。

**两种扰动形态是同一公式的两支**:
  突加(投入即满幅):踢击 |Z(0)| = εJ 必须已超过被压小的守卫 ρ_g
    G1 实测 1.18665e-04,闭式 +0.30%;idx2 实测 7.49597e-03,闭式 +0.55%
  缓升(包络慢慢涨):没有踢击,要等守卫自己消失 α_eff = 0,即
    **ε_ramp = 2√(α/Re c_x)** = 1.628721e-04(G1)
    观测窗收敛检验(ramp 300 周期后保持 400/1600/6400 周期):
      +25.01% → +5.74% → **+0.94%**
    ——初测的 −20% 是观测窗系统偏差(该支上逃逸速率 2|α_eff| 在阈值处
    按构造趋零,窗口偏差必然最大),窗口足够长后闭式成立。
  缓升/突加 = 1.38(G1)。**同一台机器,慢慢长起来的振荡能多扛 38%**。

七、PCC 量是观测值:临界摆幅是否频率盲 / 通道盲(pccrobust)
═══════════════════════════════════════════════════════════════════
PCC 的 P/Q/V 是观测量,不是可指定的输入——它们是外生输入经器件动态后的
投影,与失稳同时发生,是**共症不是原因**。因果输入仍是那五个自由变量。
所以 PCC 侧的判据只能是**监测线**,不能是施策点;要治必须回到通道上
(X_g / 增益 / 指令滤波)。

正因为只能观测,判据必须与"是谁推的、在什么频率上推的"都无关。测:

═══════════════════════════════════════════════════════════════════
八、多源同时波动:侵蚀是否可加(addit / addit2 / pdiag)
═══════════════════════════════════════════════════════════════════
往多机走时,不同连接点的量都只是观测值,归因不可得。闭式对此有明确说法:

  α_eff = α − Σ_i Re c_x^(i) |a_i|²      侵蚀:标量相加
  Z(0)  = Σ_i ε_i J_i e^{iψ_i}           踢击:相量相加

G1 margin 0.10,同时驱动 V(r=0.90)与 P(r=0.62),混合比 s 从 1 扫到 0:

**A) 突加投入**(踢击存在),预测 vs 实测:
  s=1.00  +0.31%   s=0.75  +0.09%   s=0.50  +0.16%
  s=0.25  +0.28%   s=0.00  +0.19%
  → 两条相加规则一起用,五个混合比全部 ≤0.31%。
  → 但两个踢击的相位差是 **161°**(近反相),所以混合阈值比任一单通道
    **高 1.59–2.27 倍**——两个扰动同时来反而更安全。代价是:突加协议下
    阈值依赖相对相位,而相位恰恰是观测里最难可靠拿到的。免归因时只能取
    保守界 |Z(0)| ≤ Σ ε_i|J_i|。

**B) 缓升**(无踢击,侵蚀独自决定),预测 α = Σ Re c_x^(i)|a_i|²:
  s=1.00(纯 V)      −3.55%   hold 1600
  s=0.50(V 主导混合) −2.98%   hold 1600
  s=0.00(纯 P)      **+23.06%**
  → 前两格误差相同(同一观测窗偏差,该支逃逸速率在阈值处趋零),
    两者只差 0.6 个百分点 ⇒ **可加性成立,且不需要知道是谁在推**。
  → 纯 P 格的 +23% 不是可加性失败,是**换了节点**。诊断(pdiag):
    该格逃逸时侵蚀才 Re c_x a²/α = 0.687,守卫仍在(α_eff = 0.31α)。
    查受迫轨道自身的 Floquet 乘子(pdiag2,频闪不动点 + 单值矩阵):
      ε/ε_meas   0.90    0.95     0.98     1.00     1.02
      |μ|        0.99446 0.99849  1.00113  1.00299  1.00493
    复共轭对在 0.95→0.98 之间穿越单位圆 ⇒ **是 B1b(受迫轨道自身失稳,
    Neimark–Sacker)先绑定**,不是 B3。该格本就不该用侵蚀支判。

**结论**:阈值是**各节点的最小值**,哪个节点绑定取决于通道与频率;
可加性是 **B3 节点内部**的性质。在 B3 绑定的工况下,多源同时波动可以
把各自的侵蚀量直接相加,无需归因——这正是往多机推时需要的那一步。

═══════════════════════════════════════════════════════════════════
九、通道之间是不是一个线性变换(chanlin)
═══════════════════════════════════════════════════════════════════
踢击系数 J 对 f_u 线性;若侵蚀系数也正比于 |⟨p,f_u⟩|²,整个阈值就按
1/|⟨p,f_u⟩| 标度,一个通道就决定全部。但 Re c_x 是**整个响应向量**
H = (iω_p I − A)^{-1} f_u 的二次型(经和频/差频/直流三个二阶解),不是
模态投影的二次型,所以这条不是定理,是器件性质。直接算(纯线性代数):

  形状因子 Re c_x/|⟨p,f_u⟩|²,以 V 为 1:
    r      V       P       Q
   0.60  1.0000  0.7322  0.7322
   0.75  1.0000  0.8394  0.8394
   0.90  1.0000  0.9280  0.9280
   1.00  1.0000  1.0010  1.0010
   1.15  1.0000  1.1333  1.1333

  阈值比(V 为参考)vs 纯线性预测(耦合比的倒数 P/V=2.3083, Q/V=2.5014):
    r     ε_c 比 P/V   Q/V     偏离纯线性
   0.60    2.3383   2.5340      +1.3%
   0.75    2.3727   2.5713      +2.8%

   1.00    2.3075   2.5006      −0.0%
   1.15    2.1908   2.3742      −5.1%

**两条结论**:
1. **P 与 Q 严格差一个标量**——形状因子逐位相同。原因是结构性的:
   ∂f/∂P = e₃/C,∂f/∂Q = 1.5(−X_g i_dr + v_gq)/(V_dc C)·e₃,**两者平行**
   (都只经直流母线功率平衡进入)。所以这两个通道本就是同一个方向,
   算一个即可。这也解释了为什么它们在 PCC 相位签名上几乎简并
   (117.2° vs 118.8°,残差来自观测量对 Q 的直接依赖 v_gd = V cosθ − X_g Q,
   而对 P 没有)。
2. **V 与 P/Q 不是严格线性**:形状因子跨频率差到 ±25%(0.73→1.13),
   恰在共振处 r=1.00 相等。但阈值比只偏离纯线性 −5%…+3%,因为
   ε_c = r_g/√(J² + Re c_x/(4Re c₁)) 里 J²(严格线性)承担了约一半权重
   (r=0.9 处 J²=2698 vs Re c_x/(4Re c₁)=3092)。

**判据**:两个通道的 f_u 平行 ⇒ 严格线性,只算一个;不平行 ⇒ 各算各的
c_x,但若只要 ~3% 精度,按 1/|⟨p,f_u⟩| 外推在 r ≤ 1 够用。**前提是绑定
的节点不变**——纯 P 在 r=0.62 换成 B1b 后,任何线性外推都失效。

═══════════════════════════════════════════════════════════════════
十、判据里的通道索引可以去掉(obsalpha)
═══════════════════════════════════════════════════════════════════
树上 B2/B3/B4 的判据都按通道索引,若扰动无法归因这看着是致命的。但通道
对判据的全部作用只经过两个标量,而**两个都可测**:

(i) 踢击与**观测到的**受迫模态幅值之比:
      |Z(0)|/A_obs = |λ||iω_p−λ|/|ω_p²+λ²| = **|λ|/|λ+iω_p|**
    f_u 精确约掉——只依赖 ω_p(频谱可读)与 λ。踢击侧不需要溯源。
(ii) 侵蚀后的阻尼 α_eff = α − Re c_x|a|²,它**就是受迫轨道的 Floquet
     衰减率**,也就是环境数据做模态辨识测到的那个阻尼(被侵蚀后的值,
     不是设计值 α)。

(ii) 的验证(G1 margin 0.10,r=0.90,受迫轨道按频闪不动点延拓 + 单值矩阵):

  ch  frac  ε           A_obs/r_g  Floquet 衰减率  α−Re c_x a²   误差
  V   0.3   3.5708e-05   0.3891    0.095168      0.095194     +0.03%
  V   0.5   5.9513e-05   0.6485    0.086575      0.086648     +0.08%
  V   0.7   8.3319e-05    0.9078   0.073680      0.073831     +0.21%
  V   0.9   1.0712e-04    1.1672   0.056474      0.056741     +0.47%

  (全表 12 行:三通道 × 四个驱动水平,误差 +0.00…+1.56%)

→ **α_eff 可测**,而且在各通道自身阈值的同一比例上,(A_obs, α_eff) 这对
  观测量跨通道只差 2–3%(frac=0.9:A_obs/r_g 1.167 vs 1.190;
  衰减率 0.0565 vs 0.0582)。

于是判据可以整条写成**只含观测量**的形式:

  ★ (|λ|/|λ+iω_p|) · A_obs   vs   √(α_eff / Re c₁) ★

  A_obs:观测到的模态振荡幅值(任一 PCC 量除以它的模式形状分量)
  ω_p  :频谱读数
  α_eff:辨识出的模态阻尼
  λ, Re c₁:器件属性,与通道无关

**通道在任何一步都不出现。**树上的通道索引是"按输入 ε 参数化"带来的,
换成按观测量参数化就没有了。这也事后解释了为什么临界 PCC 电压摆幅能把
533 倍的输入侧变化压成 1.9 倍——不是巧合。

**仍然需要通道的地方**(如实列出):
  - 设计/预测(在通道 X 上加多少波动会怎样)——但设计时通道是已知的;
  - 模型本身(λ, c₁, 工作点)必须对——这是模型风险,不是溯源风险;
  - 哪个节点绑定——但这也可从频谱分辨:B3 在 ω₀ 上增长;B1b(NS)出现
    新的不可通约频率;B2(参数舌)出现次谐波 ω_p/2。

═══════════════════════════════════════════════════════════════════
十一、判据不需要模式辨识——一般性证明与三个实例(decayline / gfmobs2)
═══════════════════════════════════════════════════════════════════
**命题**:相对裕度可由**单一标量观测量**的时间序列读出,不需要模式形状、
不需要通道、不需要模型系数。

**证明**(不依赖边界是什么对象):
(I) 边界是余维一且法向双曲,故逃逸受**单个标量** ρ 支配,存在自治标量律
    ρ̇ = F(ρ),F(ρ_B) = 0,F 未知。
(II) 任一观测量到领头阶是状态的固定线性泛函,故其包络 a_g = κ_g ρ,
     κ_g 未知但恒定(这正是模式辨识要求的量)。
(III) 定义只用观测量的局部速率 D_g(a) := −ȧ/a。则
       D_g(a) = −F(a/κ_g)/(a/κ_g)
     即 D_g 与 D(ρ) 是同一个函数,只差自变量的一个标度。于是
       D_g 的零点在 a_B = κ_g ρ_B,
       a/a_B = ρ/ρ_B          ← **κ_g 精确相消,对任意 F 成立**

**一句话**:裕度是**比值**,速率是**对数导数**,两者在 a → κa 下都不变;
模式形状只以这个标度出现,故二者结构上不可能依赖它。模式辨识算的正是 κ_g
——一个会被约掉的量。

**随情形变的只有"用哪个标度不变速率"**,由"哪个速率在边界上趋零"定:
  边界 = 工作点旁的不稳定极限环 → **径向衰减率** −ȧ/a 在此趋零
  边界 = 鞍点/分界线            → **振荡频率** 在此趋零(周期对数发散)
  边界 = 鞍结                    → 漂移速率趋零
三者都标度不变,故都不需要 κ_g。

**而且"用哪一个"本身可观测**:D_g 对 a² 的**斜率符号**就是 sign(Re ℓ₁):
  负斜率 → 阻尼随幅值下降 → 亚临界 → 有近旁守卫 → 用零点
  正斜率 → 阻尼随幅值上升 → 超临界 → 无近旁守卫 → 改用频率律
树上 A3/A5/B3 那个节点因此变成一条 ringdown 就能读的量。

**三个实例的实测**(全部直接在原始信号上取相邻极值,零投影零模型):

 (a) GFL G1(亚临界守卫环),PCC 电压差信号,147 个包络点:
       拟合 rate = 0.100117 − 1.2240e3 a²(**负斜率 = 亚临界** ✓)
       截距 0.100117 vs α = 0.1        → **+0.12%**
       零点 9.04417e-3 vs 直接量到的守卫摆幅 9.71145e-3 → −6.87%
       (差值是守卫环的谐波成分;方向保守——临界摆幅偏小,裕度用量偏大)

 (b) GFM M2(超临界,无近旁守卫),角度信号小幅 ringdown:
       拟合 rate = 0.220367 **+1.7345e-1** a²(**正斜率 = 超临界** ✓)
       截距 0.220367 vs −Re λ = 0.220400 → **−0.015%**

 (c) 鞍点分界线(GFM),从 0.97×角裕度 ringdown,半周期对幅值,
     按单摆自身的**对数律** T_half = p + (1/λ_s) ln(1/(A_sep − A)) 三参数拟合:
       M2: 分界线在 0.9842 × 角裕度  → **−1.58%**
       M4: 分界线在 0.9701 × 角裕度  → −2.99%(仅 4 点,D=0.5 衰减太快)
     ——前一版用二次外推给 0.77 × 角裕度(−23%),函数形式选错;对数律
     是单摆分界线的正确形式,已改正。

**本轮改正的错误**:gfmobs 第一版把符号标签写反了(rate = α − Re c₁a²,
故负系数 = 亚临界)。M2 实测 +1.73e-1 是**超临界**,当时印成了"subcritical"。
**待核**:M4 小幅 ringdown 测出**负**斜率(亚临界),与"GFM 普遍超临界"
这条旧表述不一致,需与解析 ℓ₁ 对照后再定论——本轮不改结论。
