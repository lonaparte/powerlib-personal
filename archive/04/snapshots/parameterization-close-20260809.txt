结论:
- **判据在 4.2 倍裕度范围内保持 ≤0.36%**——原来只在 α=0.10 一点上验证过。
- 标度:log-log 斜率 = ln(1.6625/0.84720)/ln 4 = **0.4867**(不是 1/2)。
  r_g ∝ √α 精确,偏离来自 |λ − iω_p| 与 |⟨p,f_V⟩| 的弱 α 依赖。
- **ε_est/ε_c = 1.5411 / 1.5469 / 1.5458 / 1.5444 / 1.5442**——五点常数,
  ±0.2%。即闭式估计的标度正确,缺一个与 α 无关的 O(1) 几何因子(见三)。

扫描的上端点(alphatop + modecross):margin 从 0.230 到 0.235 之间,
margin_point 的解从 P0=1.45480(ω₀=32.44,Re c1=+1234)跳到
P0=1.40949(ω₀=53.32,Re c1=−50)。**这不是 Bautin 点**(第一次读成
退化 Hopf 是错的,此处更正):P0 与模态频率同时跳变,是 Re λ(P) 非单调
造成的**模态交叉**——裕度超过约 0.23 后,最弱阻尼的振荡模态换成了另一支。
换句话说,标度律陈述在"由 Hopf 点连续延拓出来的那一支临界模态"上有效,
上端点由模态交叉给出,不是数值失败。

二、λ_u 与逃逸时间律(开口 2,已闭合)
═══════════════════════════════════════════════════════════════════
组:idx17(G1 with kp=55, ki=1200, Xg=0.40),margin 0.08,r=0.92。

(a) **先发现一个测量系统误差:观测窗偏差。**
    逃逸时间对数发散,所以"在 N 个驱动周期内是否逃逸"给出的阈值就是
    "逃逸时间 = N" 那一点,系统性高于真阈值。
      idx17 格:ε_c(400 周期) = 7.29318e-3,收敛值 7.09902e-3 → **+2.73%**
      α 扫描格:ε_c(400) = 1.18662e-4,ε_c(1000) = ε_c(4000) = 1.18653e-4
                → **+0.0077%**(9 位相同,已收敛)
    即该系统误差是**逐格不同**的,大小由 λ_u 决定,在 λ_u 被强迫压得很低的
    格上才显著。α 扫描表(一)的数字因此不受影响;审计里"T=60 vs 200 s
    差 +0.00%"的旧收敛检查在它自己那格是对的,但**不能外推到别的格**。

(b) **λ_u 的正确估计器,并用精确值定标。**
    ε=0 时答案已知:守卫环的不稳定 Floquet 指数 ln|μ_u|/T_c = 0.16411260 /s
    (规范形 2α = 0.16,偏 +2.57%)。两种估计器对表:
      环平均(不变横向方向场,配点环上迭代 + Fourier 移位):
        K=32 → 0.163721(−0.24%);K=64 → 0.164087(**−0.016%**)
      沿轨道幂迭代(误差 ~1/N):
        N=1000 −3.69%,2000 −2.93%,4000 −1.30%,8000 −0.74%,
        15800 −0.41%,尾平均 −0.36%
    → 幂迭代收敛太慢(此前 lamu2 的 N=1200 结果 −3.8% 就是这个原因);
      **环平均是正确估计器**。此前 lamu3 的环平均给 +92%,原因是
      growth 用了插值后的 |V(θ+ρ)| 作分母且没有做符号连续化;修正后
      与精确 Floquet 指数吻合到 −0.016%。

(c) **逃逸时间律的真斜率。**
    旧值 "81.114 个驱动周期" 是在 d = ε/ε_c − 1 ∈ [0.02, 0.8] 上、并且用了
    偏高 2.7% 的阈值拟合出来的**弦**,不是渐近斜率。用收敛阈值 ε* 重测:
      d=3e-5 → 1748.96 周期;1e-4 → 1497.73;3e-4 → 1275.83;1e-3 → 1031.00
      逐段弦斜率:208.67 / 201.98 / 203.35 → **204.7 ± 3.4 周期/e 倍**
    预测:
      **1/(λ_u T_d) = 206.14 周期**(λ_u(ε*) = 0.0510747 /s,K=64)
      **误差 +0.72%**
      无强迫代用值 1/(2α T_d) = 65.80 周期 → −68%
    → 逃逸时间律 t_esc = (1/λ_u) ln(1/d) 闭合;λ_u 是守卫不变曲线在阈值处的
      横向 Lyapunov 指数。斜率对 ε* 极敏感(ε* 差 3.6e-5 相对量 → 斜率差 8%),
      所以 ε* 必须用长窗二分(精度 ~1e-8 相对)而不是拟合。

(d) **撤回**:lamu6 那次"用轨迹直接测 λ_u"的尝试作废——它把驱动放在
    ε_c(400)(高于真阈值 2.7%),轨迹根本不贴着守卫曲线走(最近距离
    0.033 r_g 之后直接跨越 0.033→0.41 r_g),拟合对纯指数的偏离 87%,
    给出 +64%。该数字不作数,已用 lamu7 在 ε*(1+3e-4) 上重做。

(e) **独立第二条验证(lamu7):沿逃逸轨迹直接量 λ_u,不涉及任何阈值精度。**
    驱动放在 ε*(1+3e-4)(ε* 与 (c) 的独立复算吻合到 1.6e-8 相对量),
    轨迹在 1275.8 周期后逃逸,对守卫曲线的最近接为 3.786e-4 r_g;
    在离曲线足够近的窗口内拟合 ln(频闪距离):
      距离窗 [1e-3, 1e-2] r_g(663 个频闪点):λ_u = 0.0508130 /s → **−0.40%**
      距离窗 [2e-3, 3e-2] r_g:+2.56%
      距离窗 [1e-2, 1e-1] r_g:+11.16%(已离开线性域,系统性偏大)
    环平均给 λ_u = 0.0510147 /s(1/(λ_u T_d) = 206.379 周期)。
    → 逐窗漂移方向与幅度符合"离曲线越远越非线性"的预期;最内窗
      **−0.40%**。加上 (c) 的 +0.72%,机理由两条独立路径各自验证。
    注:单步增长率随环上相位振荡(对纯指数的最大偏离 ~60%),这是
    横向增长率的 θ 依赖,不是拟合失败——Lyapunov 指数是环平均量,
    663 点的拟合正确地做了这个平均。

三、闭式层 −12% 缺口的定位(附带,原不在清单里)
═══════════════════════════════════════════════════════════════════
判据层(4D 不变曲线)已 ≤0.4%;但"闭式尺度"这一层有系统偏差,逐层查清:

  层次                                    误差(α=0.05/0.10/0.20)
  (i)  线性响应达到守卫半径 ε_est          +54.1% / +54.7% / +54.5%

  (iv) 4D 精确 + 卷绕翻转判据               −0.36% … +0.21%

  逐条排除:
  - **非临界方向的 O(ε) 响应经二次项回授**(与参数舌同一个对象):
    系数 |b| = 6.1–7.8e3,|εb|/α = 6.5–12.8(即调制幅度是 α 的十倍),
    但把它加进约化模型只改变阈值 −0.04 … −0.35% → **排除**。
    原因:r=0.9 处该项远离一切共振,平均掉了。
  - **三次截断把守卫几何弄歪了**:实测 4D 守卫环的模态幅值与排斥率
    A_g/r_g = 1.0036 / 1.0072 / 1.0143,κ/2α = 0.9982 / 0.9963 / 0.9919;

    → **排除**。
  - **读出方式**:物理检测器 vs 模态半径 |⟨p,y⟩| = 5 r_g,三个 α 全是
    +0.00% → 排除。
  - (iii) 的 +0.13% 是判决性的:**同样在三次截断下,保留四个状态就对了,
    压到一个复模态就差 12–14%。缺口整体属于单模约化,不属于多项式截断。**

四、ω_g 慢带(开口 3,已闭合)——并顺带改正判据的表述
═══════════════════════════════════════════════════════════════════
组:G1 margin 0.10,ω_g 通道,dw(t) = a sin(ω_s t),突发投入。

驱动周期不再取整数比(整数比让 ρ=0 落在最强锁频点),改由守卫环周期定:
  **T_d = (8 + φ) T_c,φ = (√5−1)/2** → a=0 时 ρ/2π = φ = 0.618034(黄金比,
  离一切锁频点最远)。ω_s = 3.75524 rad/s = ω₀/8.6276,仍在原慢带内。
  实测 a_c = 0.9427837 rad/s(12 vs 40 驱动周期:+0.000%),
  相位摆幅 14.38°。

(a) 守卫不变曲线从 a=0 一路延拓到 1.05 a_c,残差 ≤1.4e-10;
    ρ/2π 从 0.618 被拖到 0.331,**穿过 1/2 与 3/8 都没有破裂**
    ——所以"慢带里曲线被锁频破坏"这个猜测不成立,曲线是真的。
(b) 绕数判据(模态平面内,绕 st):a_flip = 0.85717 → **−9.08%**。
(c) 绕参考点的对照(flipfix,两个通道同一脚本):
      V  通道:绕 st → +0.13%;绕受迫不动点 x_a → 1.35 a_c 内不翻转
      ω_g 通道:绕 st → −9.08%;绕 x_a → 1.35 a_c 内不翻转
    → **st 是对的参考点**(协议就是从 st 投入),"应该绕 x_a"这个担心被否证。
(d) 那么 −9% 来自哪里:绕数是把 4D 曲线投影到临界模态平面后数的,
    它是"st 是否在守卫曲线稳定流形内侧"的**投影代理**。慢带里受迫不动点
    离 st 有 1.49 r_g(V 通道只有 0.65 r_g),曲线强烈变形,代理退化。
(e) **锐利判据 = 着陆(点→不变曲线异宿连接)**,不含任何投影:
      a/a_c = 0.900 → 轨迹到守卫曲线的最小频闪距离 0.42969 r_g
      a/a_c = 0.950 → 0.25428 r_g
      a/a_c = 0.980 → 0.15403 r_g
      a/a_c = 1.000 → **0.00153 r_g**
    距离在阈值处塌两个量级。按局部斜率 ≈7.6 r_g /(单位 a/a_c)换算,
    残差 0.00153 r_g 对应 **Δa/a_c ≈ 0.02%** → 该格闭合。

判据层次(更新后的表述):
  - **锐利对象**:轨迹从 st 出发着陆到守卫不变曲线上(异宿连接)。
    两个通道都成立(V 通道 r=0.90 早前已测,着陆残差 2.8e-8)。
  - **廉价代理**:模态平面内守卫曲线绕 st 的绕数翻转。快带/近共振
    ≤0.4%;慢带(受迫位移 ≳1.5 r_g)退化到 −9%。代理的适用条件现在
    是可判的:比较 |x_a − st| 与 r_g。
