## 研究问题(founding question)

**单机情况下,参数或强迫振荡导致的、小信号稳定性与暂态稳定性之外的稳定性问题
有哪些(GFL 与 GFM 都要涉及)?**

工作纪律(全程强制):机理推导优先,禁止拟合常数;每条结论 5–21 组参数宽验证;
所有 >1% 误差不接受——无论可否解释,必须从机理上找解法直到达标;数值解不算
终点,要求解析解。

## 对象模型

- **GFL**(4 状态:θ, x_pll, Vdc, ξ):PLL(kp, ki)+ 直流电压控制(kpv, kiv, C),
  电网阻抗 Xg。基准组 G1: kp=50, ki=1000, kpv=1, kiv=50, C=0.01, P=1.0, Xg=0.5。
  权威实现 `scripts/selfhead.py`(自包含,防清空)。
- **GFM**(4 状态最小 VSM:δ, ω, Pf, Qf):M, D, 无功下垂 mq, 滤波 ωc。
  参数组 M1–M5,权威实现 `scripts/gfmlib.py`。

## 统一理论(最终形态)

1. **守卫对象(S1)**:亚临界 Hopf 在稳定平衡点旁留下不稳定极限环
   (半径 √(α/Re c1),Floquet 指数 κ=2α);加持续强迫后变形为频闪映射的
   **不稳定不变环面**(Fourier 配点 K=32 + Newton,解析块 Jacobian)。
2. **突发失稳阈值 = 环面模向绕数翻转(winding flip)**:模向回路
   ⟨p, u(θ)−st⟩ 绕原点的绕数翻转 = 平衡点被守卫环面的稳定流形包络吞没。
   GFL 20/21 组阈值误差 ≤0.2%。r=0.90 处已严格证实阈值即
   点—环面异宿连接(着陆残差 2.8e-8,旋转数吻合 0.03%)。
3. **失效模态由模态通道决定**(频率/幅值二分):
   - 频率主导模态(θ 份额 0.80–0.95,强亚临界,2–5 Hz 族)→ **失步**;
   - 幅值(Vdc)主导模态(Vdc 份额 0.90–0.97,弱亚临界,10–14 Hz 族)→
     **直流电压崩溃**(VDC-COLLAPSE)。
   通道分解 13/13 组一致。强类逃逸实为联合失控:Vdc 软越限(2%)先于 θ 判据。
4. **GFM 是纯频率型设备**:普遍超临界(无 S1 守卫环面);模态 91% 在 ω 通道,
   E 权重 0.3%;**"直接强迫失步到 40% 电压振荡都不存在"已于 2026-08-09
   撤销**——该结论仅在 M1@Xg=0.10 单组测过,重测五组后 M2/M3/M5 在
   4.9–8.8% 源电压振荡(共振)即真失步,免疫来自角裕度而非内电势缓冲,
   机制为盆边界(鞍点周期轨道稳定流形)扫过工作点;详见
   snapshots/gfm-direct-correction-20260809.txt。响应饱和(线性估计偏差
   50×)与组合泵浦阴性、慢穿越 P_H 有界仍成立。GFM 的振荡风险全部走
   参数共振(D)与吸引域侵蚀(E)通道。

20. **第二轮自查**(见快照 §15)改了四处:多音闭合的对照补做(通过);剩余
    0.5% 的归因**撤回**(不是交叉系数一家,五阶项的非自治多音形式未实现,
    哪个主导未分离);Kramers 斜率 0.9898 **不该报四位**(四点拟合,窗口一动
    变 0.9520,应读"与 1 相符 ~5%",稳的是排序不是数值);GFM 准静态带
    **不该叫闭合**(2–9% 未做机理闭合)。传感器共同偏差的归因补验通过。

21. **第三轮自查**(见快照 §16)推翻了上一轮的两条。GFM 准静态残差**不是
    开放项**:超出 ε_qs 的部分除以 ω_p 是常数(线性!),机理是鞍结**慢通过**
    ——正是本树自己的 B4,我没连起来。切向趋近下问题普适化为
    X′ = λ − τ² + X²,λ* = **1 精确**(X = τ 是精确解),于是
    ε_c = ε_qs + ω_p √(ε_qs/(2ab)),零拟合常数;四格 pred/meas =
    0.974…0.998(ab 跨 208 倍),加上该项后误差 **≤0.08% / ≤0.32% / ≤1.50%**
    (ω_p/ω₀ = 0.05/0.10/0.30,原为 4.75/9.10/22.69%)。传感器那条的**归因也
    错了**:不是分箱(喂精确 ρ(t) 时它无偏,斜率误差 +0.046%),是 filtfilt +
    Hilbert 对记录**尾部**的边缘效应(窗尾包络误差 −22%);而且那个"偏差"
    根本不稳定,随窗长在 +113% 与 −24% 之间摆。改用闭式解拟合 + 剔尾后
    α 定到 **−0.02%**、Re c1 定到 **+0.41%**,跨 100 倍 κ_g 的离散
    **0.037%** —— 结论由"不变但偏 14%"升级为"不变且准确"。

22. **第四轮自查**(见快照 §17):撤回一个数与一个假说——GFM M2 的"窗口跳变
    −10.36%"是**逃逸集被打散**(0.9800 不逃 / 0.9825 逃 / 0.9850 不逃 /
    0.9875 逃),该格没有二分阈值这个对象,归 B5;并查了波及范围,**四个承载
    头条数字的格逃逸集全部是干净的单次转变**,主结论不受影响。另有两次"看
    起来该有"的改进被实测否掉并记录原因(多音的一致五阶形式、GFM 的传递
    因子复合)。判定树新增一条前提:**报二分阈值前必须先验逃逸集是区间**。

23. **第五轮自查**(见快照 §18)按"要公式参数不要具体数字"重审,两处不合格
    且都补上了。**多音判据有闭式**:那条非自治方程是 Bernoulli 型,
    $u=|\zeta|^{-2}$ 精确线性化,给出 **|Z(0)|_c = ρ_g/√G**,
    G = 2α_eff∫₀^∞ e^{−2α_eff s+2Ψ(s)}ds,Ψ 是有界的拍频项。整个多音效应
    压缩成一个具名参数 G(实测 0.830–1.942),单音时 Ψ≡0、G=1,旧公式是
    G=1 的特例。17 格闭式与 ODE 积分逐位相同(0.521% / 1.54%)。
    **Kramers 前因子也是被预测的**,此前推出来却当自由截距用掉:约束斜率
    为 1 后,实测常数是 **√(2π)** 而推导给 √π——比值 1.412–1.417 对
    √2 = 1.41421,**吻合 0.02–0.2%**;函数形式证实,数值常数差一个 √2
    (记账错误,未定位)。

24. **第六轮**(见快照 §19)做掉 §18.3 自列的三条待办,并撤回一个刚提出的
    分解与一条在册标度。
    - **GFM 慢通过二阶**:待办写的是"λ*(γ) 可算",可算的其实是一整台机器。
      未扰动内问题在 λ=1 有精确分离子 X=τ,伴随即 e^{−τ²},故任意扰动 Φ 对
      阈值的移动是一个高斯矩 **λ* = 1 − (1/√π)∫e^{−τ²}Φ(τ,τ)dτ**,而**宇称
      干掉一半**(分离子上奇的项贡献恰为零)。打靶验证七个扰动,含**两个被
      预测的精确零**。用到真实余弦驱动 + 曲率自洽,得
      **ε_c/ε_qs = 1 + ν + (3/8)ν²**,ν = ω_p/√(2abε_qs),3/8 = 1/2 − 1/8。
      普适曲线 F(β) 独立复核(0.37547 → 3/8)。ω_p ≤ 0.1ω₀ 的 20 点最大误差
      由 0.322% 降到 **0.032%**。
    - **Kramers 前因子的 √2 定位并撤回**:它不是常数。实测/渐近式逐点是
      0.286…1.494…1.277,是次阶修正的形状——与已撤回的"双重计数"同一种
      错误(在渐近未成立的窗口读渐近常数)。改用**精确求积**,七点零常数
      复现(均值 0.9947);Laplace 展开下一阶给
      **T = √π·√(D̃ Re c₁)/α_eff²·e^X·[1 + 1/X + O(1/X²)]**,1/X 的系数
      **恰为 1**(井与势垒各半),而 1+1/X = √2 恰在 X = 2.414 —— 原拟合窗
      X>1.4 的重心。**C = √π 是对的**。
    - **传感器容差写成标度律**:Cov(θ̂) = (2σ_n²/(f_s κ_g²)) M⁻¹,
      M = ∫∂ρ∂ρᵀdt。**带宽不出现**——故在册的"带通压掉 √(BW_f/BW_n)"这句
      **撤回**(那说的是瞬时读数,不是判据参数)。11 格 MC 跨 κ_g×100、
      σ×16、BW×10、f_s×4、窗口×2.25 落在 0.89–1.11,唯一例外处公式自报出
      定义域。容差:κ_g ≥ (σ_n/(eα))√(2(M⁻¹)_αα/f_s)。
    - **撤回一个分解**:同轮曾用 Lyapunov–Schmidt 给 C₂ 的折叠专属修正
      (a₂ 与滞后 μ),预测 +1.52…+52.35 对实测 0.33…0.39。该分解**规范依赖**
      (ξ→ξ+σD 在 a₂ 与 κ 之间搬运,而 κ 只在二阶微扰论出现),取部分和不是
      近似而是取了个不守恒的量。项已按标度定全、二阶闭式已写出,**没做完就
      不报**;只报规范无关的 3/8 与实测界 |C₂ − 3/8| ≤ 0.042。

25. **第七轮**(见快照 §20)把 §19.2 留的待办做完,结论是"机器对、应用不成立",
    并查清了一条协议问题。
    - **C₂ 余项的机器做完并验过**:O(ν) 上的项由标度唯一确定(一阶 (0,2)、
      (2,1)、(4,0);二阶 (1,1)、(3,0);外加两个非单项的滞后项 μ_D ξḊ 与
      μ_ξ ξ²ξ̇——后者只因这是 4 态约化才存在),二阶闭式
      λ₂ = −(1/√π)∫e^{−τ²}[u² + Φ_X u],u(τ) = ∫e^{τ²−s²}Φ。
      **11 个受控格全部逐位符合**:标量 10 格(含五项同时上)+ 两态 3 格,
      其中把滞后旋钮 λ_f 从 3 改到 1(滞后放大 9 倍)后仍逐位符合。
    - **用到 GFM 上不成立,原因具体**:A 格各项 −0.765/+1.501/−3.762/
      +1.909/−1.908/+2.982 **相消到 −0.043**,要预测的量(C₂ − 3/8 = −0.014)
      比单项小两个数量级;两条取系数路线之差(0.023)已大于被预测量,B、C
      两格的 LS 补方程在内尺度盒子上解不出。**卡点是条件数不是机理**,
      这也解释了实测 C₂ 为何四格都贴着 3/8。**不用任一路线的数字充当结论。**
    - **协议**:ω_p ≥ 0.15ω₀ 的在册 ε_c 是协议敏感的——未受迫平衡点起步 vs
      准静态支起步,δ 差最大 **12%**;而 ω_p ≤ 0.10ω₀ 上两者差 ≤1.1%(A 格
      0.000%),本轮 C₂ 只用了这一段。**逃逸集在检查过的 18 个(格,频率)上
      全是干净区间**,不是 B5 打散。换干净协议后非单调减轻但未消失。

26. **第八轮**(见快照 §21)把三条开放项闭合、否掉一个假说、撤销一条陈旧待办。
    - **C₂ 折叠专属余项闭合(四格)**:卡点是条件数,而有限差分是错的工具。
      R(ξ,D) 解析,其 Taylor 系数是 **Cauchy 围道积分**,梯形法几何收敛、
      相对误差 ~1e−16 且与阶数无关。半径扫描后 a 与独立公式**逐位相同**。
      预测/实测:A 0.3613/0.3612、B 0.3741/0.3747、C 0.3350/0.3329、
      D 0.3972/0.3940——**D 格单项跨到 ±163,99.99% 的相消被逐项预测出来**。
    - **A1 二次冲击项给出公式**:等时线投影 π(x) = ⟨p,x⟩ + Q(x,x),由
      2Q(x,Ax) − λQ(x,x) = −½⟨p,B(x,x)⟩ 在本征基下逐项对角解出
      **Q_ij = −½⟨p,B(e_i,e_j)⟩/(λ_i+λ_j−λ)**。八个方向全维实测:平均 |误差|
      **3.977% → 0.591%**,最大 **13.957% → 0.972%**。(过程中"改进反而变差"
      当场判定为自己的共轭约定 bug 并查出——小幅度下该 bug 不可见。)
    - **多音残差:假说被否 + 适用域量化**。把二阶等时线用到多音 Z(0) 上
      **0.696% → 2.814%**,**否掉**——多音的 Z(0) 是受迫轨道中心的偏移,
      不是冲击后的等时线投影。适用域改写成数:corr(a⁴/α, |误差|) = **+0.780**,
      误差(%) = 0.175 + 0.105×(a⁴/α %),**a⁴/α ≤ 1% 时 ≤0.385%**(14/17 格);
      剩 **0.175% 的地板**仍开放,但它是一个具体量不是一句借口。
    - **撤销**"Kramers 分带宽度"这条待办:分带假说本身已在第四轮撤回,
      没有分带就没有带宽——不是没做完,是对象不存在。

    - **共振带重测后改判**(§21.5):干净协议扫 0.10–0.90 ω₀。B 格在
      0.70–0.80 ω₀ 上 **ε_c/ε_qs = 0.835 / 0.813,低于 1**——而 B3-ii 的对象
      ("边界被推到工作点")按定义要走完 ε_qs 的距离,所以那里它根本不是约束。
      **共振带不是 B3-ii 公式精度不够,是把公式用到了它的对象已不构成约束的
      频段**;高频侧的约束换成对摆动模态的共振泵浦(B1b/B2 一侧),需要的幅值
      更小因而先触发。附带:带内阈值非单调(A/B/C 在 0.50 ω₀ 有局部极大),
      下跌深度随阻尼变轻而加深;**C@0.80、B@0.70 的逃逸集碎成非区间**
      (符号翻转 3 次),那两点不存在单值阈值,按 E 支规则不得报——是 B5。

仍开放:GFM 共振带在 ω_p ≲ 0.6 ω₀(B3-ii 仍是约束的那一段)的 Melnikov 型
闭式——对象已写进 `scripts/gfmmel.py` 且**适用域现已知**,但本轮未算出
