## 研究问题(founding question)

**单机情况下,参数或强迫振荡导致的、小信号稳定性与暂态稳定性之外的稳定性问题
有哪些(GFL 与 GFM 都要涉及)?**

工作纪律(全程强制):机理推导优先,禁止拟合常数;每条结论 5–21 组参数宽验证;
所有 >1% 误差不接受——无论可否解释,必须从机理上找解法直到达标;数值解不算
终点,要求解析解。

## 对象模型

- **GFL**(4 状态:θ, x_pll, Vdc, ξ):PLL(kp, ki)+ 直流电压控制(kpv, kiv, C),
  电网阻抗 Xg。基准组 G1: kp=50, ki=1000, kpv=1, kiv=50, C=0.01, P=1.0, Xg=0.5。
  权威实现 `scripts/selfhead.py`(自包含,防清空)。
- **GFM**(4 状态最小 VSM:δ, ω, Pf, Qf):M, D, 无功下垂 mq, 滤波 ωc。
  参数组 M1–M5,权威实现 `scripts/gfmlib.py`。

## 统一理论(最终形态)

1. **守卫对象(S1)**:亚临界 Hopf 在稳定平衡点旁留下不稳定极限环
   (半径 √(α/Re c1),Floquet 指数 κ=2α);加持续强迫后变形为频闪映射的
   **不稳定不变环面**(Fourier 配点 K=32 + Newton,解析块 Jacobian)。
2. **突发失稳阈值 = 环面模向绕数翻转(winding flip)**:模向回路
   ⟨p, u(θ)−st⟩ 绕原点的绕数翻转 = 平衡点被守卫环面的稳定流形包络吞没。
   GFL 20/21 组阈值误差 ≤0.2%。r=0.90 处已严格证实阈值即
   点—环面异宿连接(着陆残差 2.8e-8,旋转数吻合 0.03%)。
3. **失效模态由模态通道决定**(频率/幅值二分):
   - 频率主导模态(θ 份额 0.80–0.95,强亚临界,2–5 Hz 族)→ **失步**;
   - 幅值(Vdc)主导模态(Vdc 份额 0.90–0.97,弱亚临界,10–14 Hz 族)→
     **直流电压崩溃**(VDC-COLLAPSE)。
   通道分解 13/13 组一致。强类逃逸实为联合失控:Vdc 软越限(2%)先于 θ 判据。
4. **GFM 是纯频率型设备**:普遍超临界(无 S1 守卫环面);模态 91% 在 ω 通道,
   E 权重 0.3%;**"直接强迫失步到 40% 电压振荡都不存在"已于 2026-08-09
   撤销**——该结论仅在 M1@Xg=0.10 单组测过,重测五组后 M2/M3/M5 在
   4.9–8.8% 源电压振荡(共振)即真失步,免疫来自角裕度而非内电势缓冲,
   机制为盆边界(鞍点周期轨道稳定流形)扫过工作点;详见
   snapshots/gfm-direct-correction-20260809.txt。响应饱和(线性估计偏差
   50×)与组合泵浦阴性、慢穿越 P_H 有界仍成立。GFM 的振荡风险全部走
   参数共振(D)与吸引域侵蚀(E)通道。

## 检测器教训(方法论)

θ-only 命运分类器漏掉 Vdc 通道失效:弱类轨迹 Vdc→0 积分器死亡曾被记为
"捕获"。修复 = 复合检测器(θ 越限 / Vdc<0.2 / Vdc>2.5 / solver 状态检查)。
**"无事件 = 稳定"是隐藏假设**;所有长积分必须带守卫事件 + solver 状态检查。
