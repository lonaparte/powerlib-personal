# 单机并网变流器稳定性判定树

**适用对象**:单机-无穷大母线系统中的并网变流器(GFL / GFM 为两条实例路径)
**输入类**:$u(t) = u_0 + \varepsilon\cos(\omega_p t)$(最小非自治输入类)
**版本**:v3,2026-08-09。基于本战役全部已验证判据(archive/04),含 V / P / Q 三端口通道全格补测。

**构造原则**:树上每一个分岔都是一次对**可计算判别量**的测试;设备名(GFL/GFM)不是判别量,只是两条穿过树的典型路径(§5)。同一判别量(如 $\operatorname{sign}(\operatorname{Re}\ell_1)$)在不同节点重复出现时,各处判定的是不同的问题(饱和性、边界对象存在性),故分别设节点。

---

## 0. 对象

$$\dot x = f(x,\ u(t)),\qquad u(t) = u_0 + \varepsilon\cos(\omega_p t)$$

- 状态 $x$(有储能/积分动力学):GFL $(\theta, x_{\rm pll}, V_{dc}, \xi)$;GFM $(\delta, \omega, P_f, Q_f)$。网络准稳态相量近似代数化。
- 端口量 $u$(运行中可动):电网电压幅值 $V$、功率注入/指令 $P$、无功指令;电网频率为隐含通道。外界影响仅经端口量进入,"参数振荡"与"强迫振荡"同一对象。
- 设计常数(定义 $f$):增益、惯量、阻尼、下垂、滤波带宽。
- 输入类选择依据见 §10b:周期性是保持渐近判决良定的最弱时间依赖;$(\omega_p,\varepsilon)$ 两参数张满非自治新可能完备清单且 $\varepsilon=0$ 边即自治世界;单频为领头阶原子;实际扰动类窄带。

 └─ ε ≠ 0 ──────────────────────────────→ 进入 B 子树(非自治)

═══════════════ A 子树(自治) ═══════════════

【A1】α > 0 ?(冻结谱裕度)

 │   【A2】Im λ_c ≠ 0 ?(越界的分岔类型)
 │    ├─ 是(复对过虚轴,振荡型;有增长振荡前兆)

 │
 └─ 是(小信号稳定)

      ├─ 否 → 叶【L0】渐近稳定(定理,无例外)。
      │   附注:若 Re ℓ₁ > 0,吸引域半径 r_c 有限且 ∝√α,
      │   为隐患;兑现只有两条路:A4=是,或 Q0 转 ε≠0。
      └─ 是

           ├─ 是 → 边界 = 不稳定极限环的稳定流形(距离 r_c;
           │   经典能量法对此类振荡型边界失配)
           │   【A6】位移长度 ≥ 位移射线与环的 Floquet
           │        稳定平面族的首交距离?
           │    ├─ 否 → 叶【L0'】衰减回平衡点(可先长潜伏)
           │    └─ 是 → 潜伏 t ≈ κ⁻¹ ln(A_vis/d₀) 后
           │        显性发散(潜伏期内与恢复轨道几乎不可分辨)
           │        ─────────────────────→ 进入 T 子树
           └─ 否 → 边界 = 伴随鞍点的稳定流形(经典几何)
               【A7】注入能量 ≥ 沿逃逸路径的势垒?
               (含滤波状态弛豫的能量边值问题,非简单等面积)
                ├─ 否 → 叶【L0'】回摆衰减

═══════════════ B 子树(非自治) ═══════════════

【B1】参考解层:锁频响应幅值方程对 a² 单调吗?

      δ = ω₀ − ω_p

 │   (直接强迫失步不发生;实测至 40% 电压振荡,响应饱和)

      一阶 = 闭曲线投影 ζ(θ)=⟨p,U(θ)−x_eq⟩ 卷绕数由 1 变 0

          ─────────────────────────────────→ 进入 T 子树

【B4】路径层闸门:ω_p ≪ ω₀ 且路径接近冻结边界吗?

 ├─ 否 → 跳过本层
 └─ 是
     【B4a】振幅方程沿路径积分逃逸吗?

      ├─ 否 → 过闸(带 O(εω_p) 拖尾的慢跟踪)
      └─ 是 ─────────────────────────────→ 进入 T 子树

【B5】精细结构闸门:边界闭曲线旋转数 ρ(ε) 处于
      低阶 Arnold 舌重叠区吗?(过渡频带)
 ├─ 否 → 叶【L3】锁频有界响应(形态按 B1/B4 记录)
 └─ 是 → 条带区:临界幅值非单值;
      仅下包络确定 —— 包络下 →【L3】;包络上逐点判定
      (对象性质,非精度缺口)

═══════════════ T 子树(失稳形态) ═══════════════

【T1】逃逸方向(临界特征向量 q)参与因子最大的状态是?

 │   → 叶【F1】失步(相角越过恢复力矩变号点后单调增长);

## 3. 各节点判据的完整表述与验证状态

### A1 / A2(冻结谱与越界类型)
标准特征值计算。A2 的物理内容:振荡型越界有增长振荡前兆;鞍结型越界前 $\omega_n\to0,\zeta\to\infty$,振荡先消失——前兆结构完全不同。

### A3 / B2a / A5 / B3(同一判别量 $\operatorname{sign}(\operatorname{Re}\ell_1)$ 的四次使用)
$\ell_1$ 由 $f$ 的二、三阶张量经中心流形闭式算出(与数值互证 $10^{-8}$)。四个节点问的是不同问题:A3、B2a 问**增长是否被三次项饱和**(决定越阈后有界与否);A5、B3 问**平衡点近旁是否存在不稳定极限环**(决定吸引域边界的几何对象与它能否被强迫移动到平衡点上)。实测:GFL 全部 21 组 $\operatorname{Re}\ell_1>0$(亚临界),GFM 全部组 $<0$(超临界)。

### A6(振荡型边界的暂态判据)
位移射线与不稳定极限环各点二维 Floquet 稳定子空间的首交。验证 ≤1%(14 点)。潜伏时长 $t\approx\kappa^{-1}\ln(A_{\rm vis}/d_0)$,$\kappa$ 验证 ≤0.26%。

### A7(鞍点型边界的暂态判据)
沿逃逸路径含滤波弛豫的能量边值问题(简单等面积不成立,滤波滞后一路耗散)。验证 ≤0.2%(6 组)。

### B1(响应支折叠)
幅值方程非单调 ⇔ 受迫周期轨道鞍结分岔 ⇔ 双稳跳变迟滞。实测窗 $|\omega_p/\omega_0-1|\lesssim10^{-2}$;亚临界机器中被 B3a 遮蔽(后者阈值恒低约一半),不可达。

### B2(参数失稳,Floquet)
$$\Big(\frac{\varepsilon|\pi|}{2}\Big)^2 > \alpha^2+\Big(\frac{\omega_p}{2}-\omega_0\Big)^2,\qquad \pi=\langle p,M_1\bar q\rangle+\langle p,B(h,\bar q)\rangle$$
失稳区由不等式自定义(给定 $\varepsilon$ 失谐半宽 $\sqrt{(\varepsilon|\pi|/2)^2-\alpha^2}$)。大幅值修正:$\alpha\to\alpha-\operatorname{Re}(\delta\lambda_{\rm DC}+\delta\lambda_{\rm lad})$,直流轨道偏移 $x_{\rm DC}=-a^2A^{-1}[B(h,\bar h)+f_{uu}+2M_1\operatorname{Re}h]$($a=\varepsilon V_0/2$),频率梯项对共轭临界通道 deflation。高次亚谐区宽 $\propto\varepsilon^n$ 可忽略;和频组合阈值为单频百余倍;差频组合不存在(两模式阻尼同号)。验证:GFL ≤0.5%,GFM 含修正 ≤0.4%。

### B3a(边界触及平衡点)
对象链:不稳定极限环 → 回归映射的不稳定不变闭曲线 $U(\theta)$(Fourier 配点 + Newton 解 $P_\varepsilon(U(\theta))=U(\theta+\rho)$)→ 稳定流形 = 吸引域边界。
- 精确判据:$\varepsilon_c$ 处存在平衡点渐近于闭曲线的异宿轨道;实测着陆残差 $10^{-6}$–$10^{-8}$,误差 ≤0.01%,失谐比 0.60–0.92 全域验证。
- 一阶判据:投影卷绕数变化;中等失谐 21/21 组 ≤0.2%;深失谐系统性偏迟(0.75/0.70/0.60 处 +0.9/+1.2/+2.3%,源于稳定流形在模式平面内超出闭曲线的横向延展),换精确判据。
- 协议纪律(实测教训):判据与测量逐组核对驱动频率;模型与实测的失稳事件判据逐字一致;测量值转录保留全精度;阈值测量须逃逸时间感知。

### B4a(慢通过/动态分岔)
系数为冻结族沿路径的已知函数;阈值 = 一维复振幅方程的逃逸边界,无代数闭式(机理即积累)。精度阶梯:基础 ≤0.9%;补受迫偏置×二次项耦合、解析五次($\ell_2$)、稳定子空间中心流形滞后(随瞬时平衡点平移的完整五阶 Taylor 模型)后 ±0.0–0.9%;GFM 侧 ≤0.2%。速率→0 连续退化为冻结判据。

### B5(旋转数锁定)
$\rho(\varepsilon)$ 扫过有理数集,低阶有理附近 Arnold 舌;失稳集为区间族,仅下包络 $\varepsilon_{\rm env}=\inf\{\varepsilon:\text{失稳}\}$ 确定。低阻尼参数在强迫背景下的多摆逃逸条带同属此类。

### T1(参与因子)
$q$ 归一后各状态分量模长。相角类 → F1;直流电压类 → F2($\dot V_{dc}$ 含 $1/V_{dc}$,跌落自加速);角频率类 → F1。通道-临界性联动为实测规律:相角族均强亚临界,直流族均弱亚临界(13/13)。

## 4. GFL / GFM:树上的两条路径

设备不进树;设备由它对各判别量的回答定位。回答由两个结构根决定:

**根一(阻尼来源)**:GFL 刚度阻尼同源($V\cos\theta^\ast$ 乘性绑定);GFM 阻尼独立常数、经滤波折损。
**根二(内电势)**:GFL 无自持电压($V$ 双重进入);GFM 自持 $E$($V$ 单重,下垂限渗)。

| 节点 | GFL 的回答 | GFM 的回答 | 由哪个根决定 |
|---|---|---|---|
| A2 越界类型 | 振荡型(复对过轴) | 逼近折叠时鞍结型 | 根一($\zeta$ 与刚度同塌 vs $\zeta$ 发散) |
| A3/B2a 饱和? | 否(亚临界,越阈跑飞) | 是(超临界,有界) | 根一(非线性坐在同步通道 vs Hopf 源于滤波滞后) |
| A5/B3 近旁边界? | 是(不稳定极限环,$r_c$ 小) | 否(边界远,鞍点型) | 同上 |
| A6/A7 暂态工具 | Floquet 平面族(经典能量法失配) | 能量边值问题(经典同构) | 同上 |
| B1 折叠可达? | 否(被 B3a 遮蔽) | 是(窄窗) | 阈值次序 |
| B2 危险工况 | 重载/弱网($\alpha$ 与 $|\pi|$ 同角恶化) | 轻载($\alpha$ 轻载最小) | 两根 → 危险区地理反转 |
| B3a | 主要失稳通道(无前兆) | 跳过(响应饱和) | 根二 |
| T1 | 相角族 或 直流电压族(按参数) | 角频率(0.91) | 模型结构 |

适用限定:GFM 结论限独立阻尼类;下垂系数增大同时把 A3/A5/B3 的回答推向 GFL 化并削弱根二的饱和保护,须重查 B3a。

## 5. 端口通道(V / P / Q):判据不变性与通道排序

通道只经两个对象进入全部判据:$f_u=\partial f/\partial u$(直接强迫)与 $M_1=\partial A/\partial u$(参数调制)。换通道 = 换这两列,**树结构、节点、公式逐字不变**——已由 P、Q 两通道全格补测实证(15 个实测格,误差 ≤0.7%,多数 ≤0.2%)。

**结构差异(决定各通道能打开哪些节点)**

| | $V$ | $P$ | $Q$ |
|---|---|---|---|
| GFL 进入方式 | 乘性 + 二次进入(同步几何与直流功率两处) | 加性线性($f_P=e_3/C$),**$M_1\equiv0$** | 经 $X_gQ$ 物理进入,符号工况依赖 |
| GFM 进入方式 | 乘性,但经 $m_q$ 被内电势缓冲(单重) | 加性线性($f_P=e_2/M$),**$M_1\equiv0$** | 经下垂,$m_q=0$ 时通道精确关断 |
| B2 泵浦项 | $t_1+t_2$ 齐全 | $t_1=0$,仅响应中介 $t_2$ | $t_1,t_2$ 均在,可相消 |

**已验证结论**

- **$M_1(P)\equiv0$ 精确成立**(两族):P 通道的参数舌纯由响应中介项 $\langle p,B(h,\bar q)\rangle$ 支撑。但阈值并不因此变高——GFL 贴折叠工况下 P 舌与 V 舌同量级($2.8\times10^{-4}$ vs $3.4\times10^{-4}$ pu)。
- **通道危险度由 $|\langle p,f_u\rangle|$ 排序**:G1 的 $|\langle p,f_V\rangle|=320$、$|\langle p,f_P\rangle|=139$,阈值比 $2.79/1.19=2.3$ 与耦合比一致。
- **B3a 判据跨通道成立**:P 强迫的突发阈值与卷绕翻转判据吻合 −0.18 / −0.06 / −0.02%(强类 + 两组弱类),失效模态与 V 通道一致(弱类恒为直流电压崩溃)。
- **GFM 的 Qref 自屏蔽**(新机理):$t_1$ 与 $t_2$ 近乎反相,$\cos(t_1,t_2)=-0.999/-0.988/-0.993$(M3/M2/M5)——$Q_{\rm ref}$ 抬内电势的直接作用被下垂环感应的 $Q_f$ 响应抵消。近全消组($|\pi|\approx0.1$)的名义阈值超出微扰域与相量模型适用域,交付形式为"域内验证稳定 + 严格下界 $\varepsilon_t\ge2\alpha/(|t_1|+|t_2|)$"。$m_q\to0$ 时 $|f_Q|\to0$、阈值 $\to\infty$——**Q 通道免疫可在设计期买断**(已逐点验证 $m_q=0.2\to0$)。
- **GFM 的"直接强迫不失步"仅限 V 通道**:$P_{\rm ref}$ 强迫在 $\pm13\%$–$34\%\,P_0$ 处失步,$Q_{\rm ref}$ 在 $\sim1$ pu 处失步(低阻尼组更早);全通道响应饱和,线性外推高估 2–40 倍。
- **P 背景侵蚀是双向且近对称的**(GFM,共振):最坏相位削 22%、最好相位抬 21%,均值近零;偏共振 ≤3%(共振选择性对 P 同样成立)。含强迫路径 BVP 预测 16/16 点 ≤0.1%。工程含义:按平均背景评估暂态裕度会漏掉最坏相位,判据须取相位最小值。
- **P 慢带是贴折叠 GFL 的最危险通道**:G1 的 Hopf 距离仅 $1.5\times10^{-4}$ pu(R17 悬崖),约 0.1–0.2% $P_0$ 的慢功率波动即失稳(误差 +0.1 / −0.2%)。

## 6. 完备性论证

稳定性判决由五要素构成;非自治性对每要素的改写即新可能的完备清单;树节点与之一一对应:

| 要素 | 非自治改写 | 树上节点 |
|---|---|---|
| ① 参考解 | 常数解→有界响应;可多支折叠/共振放大 | B1 |
| ② 线性化 | LTI 谱→Floquet 指数;冻结稳定可增长(反向:振动镇定,未开发格) | B2 |
| ③ 判决类型 | 点函数→路径泛函;滞后、延迟失稳、短暂越界无害 | B4 |
| ④ 全局几何 | 边界运动(触及)+ 边界对象新分岔(锁定/缠结) | B3, B5 |
| ⑤ 有限位移 | 快照隶属→相位依赖、被侵蚀 | A4 的非自治延拓(§7 交叉项) |

无第六要素。$\varepsilon=0$ 边(A 子树)= 自治世界的完备两分类(小信号 A1–A3 + 暂态 A4–A7),经典分类法对自治系统完备,"之外"的空间恰好等于非自治打开的空间。单频为原子(多频丰富各行不加新行);随机输入为 ③④ 的随机版本(范围外,共用几何骨架)。

## 8. 范围边界与交叉项

- 排除:单调漂移至冻结失稳(平凡,A1 覆盖其终点);随机扰动(范围外,复用几何骨架)。
- 交叉项(A4 的非自治延拓):有限位移落在 $\varepsilon\ne0$ 背景上——初值与边界都在动,阈值为强迫相位函数且被侵蚀(共振背景 1–2% 电压振荡侵蚀 10–15%,偏共振约 0.8%;低阻尼参数退化为多摆条带,归 B5 类)。$\varepsilon\to0$ 连续退化为 A6/A7。
- 可用运行域:$\mathcal U(\varepsilon,\omega_p)=\{u_0:\text{全部闸门通过}\}\subsetneq\{u_0:\alpha>0\}$;$\varepsilon\to0$ 涨回小信号稳定域。小信号域本身不缩小;缩小的是状态空间安全邻域($r_c\propto\sqrt\alpha$)与非零扰动环境下的可用域。
