# 单机并网变流器稳定性判定树

**适用对象**:GFL(锁相环 + 直流电压控制)与 GFM(独立阻尼的下垂 / 虚拟同步机)
**输入类**:$u(t) = u_0 + \varepsilon\cos(\omega_p t)$(最小非自治输入类)
**版本**:2026-08-09,基于本战役全部已验证判据(archive/04)

---

## 0. 范围与对象

$$\dot x = f(x,\ u(t)),\qquad u(t) = u_0 + \varepsilon\cos(\omega_p t)$$

- **状态 $x$**(有储能/积分动力学):GFL 取 $(\theta,\ x_{\rm pll},\ V_{dc},\ \xi)$;GFM 取 $(\delta,\ \omega,\ P_f,\ Q_f)$。网络按准稳态相量近似代数化,消去后进入 $f$。
- **端口量 $u$**(运行中外部世界可动的量):并网点等效电网电压幅值 $V$、功率注入/指令 $P$、无功指令;电网频率为隐含通道。外界对单机的全部影响仅经端口量进入,故"参数振荡"与"强迫振荡"为同一对象。
- **设计常数**(定义 $f$,不随时间动):控制增益、惯量、阻尼、下垂系数、滤波带宽。

选择该输入类的依据(详见 §8):周期性是保持渐近稳定性判决良定的最弱时间依赖(回归映射恢复全部不变集机器);$(\omega_p,\varepsilon)$ 两参数恰好张满非自治新可能的完备清单,且 $\varepsilon=0$ 边即自治世界;机制的频率选择性使单频为领头阶原子;实际扰动类(区域间振荡、次同步振荡、邻近装置振荡)本身窄带。

## 1. 判定前一次性计算的冻结量

在工作点 $u_0$ 处冻结,依次计算:

| 量 | 定义 | 用途 |
|---|---|---|
| $x_{\rm eq}(u)$ | $f(x_{\rm eq},u)=0$ | 参考解族 |
| $A(u)$ | $D_xf$ 于 $x_{\rm eq}$ | 谱、灵敏度 |
| $\alpha$ | $-\max\operatorname{Re}\lambda$ | 谱裕度 |
| $\omega_0,\ p,\ q$ | 临界振荡模式频率与左右特征向量,$\langle p,q\rangle=1$ | 全部判据 |
| $\ell_1$ | Hopf 第一 Lyapunov 系数(由二、三阶张量 $B,C$ 经中心流形闭式) | 分岔类型、吸引域半径 |
| $\ell_2$ | 第二 Lyapunov 系数(五阶规范形) | 边界排斥率 |
| $f_u,\ M_1=\partial A/\partial u$ | 参数耦合向量与灵敏度矩阵 | 强迫进入通道 |
| 参与因子 | $q$ 归一后各状态分量模长 | 事故形态判定 |

导出量:吸引域半径 $r_c=\sqrt{\alpha/\operatorname{Re}\ell_1}$(亚临界时);边界排斥率 $\kappa=2\alpha\big(1+\tfrac{\operatorname{Re}\ell_2}{(\operatorname{Re}\ell_1)^2}\alpha\big)$。

## 3. 各判据的完整表述与验证状态

### N1 参数共振(周期系数线性系统的 Floquet 失稳)

$$\Big(\frac{\varepsilon|\pi|}{2}\Big)^2 > \alpha^2 + \Big(\frac{\omega_p}{2}-\omega_0\Big)^2,\qquad \pi = \langle p, M_1\bar q\rangle + \langle p, B(h,\bar q)\rangle,\quad h=(i\omega_pI-A)^{-1}f_u$$

- 与 Hopf 分岔类型无关;失稳区(舌)由不等式自定义,给定 $\varepsilon$ 的失谐半宽 $\sqrt{(\varepsilon|\pi|/2)^2-\alpha^2}$。
- 大幅值修正:$\alpha\to\alpha-\operatorname{Re}(\delta\lambda_{\rm DC}+\delta\lambda_{\rm lad})$,其中直流轨道偏移 $x_{\rm DC}=-a^2A^{-1}[B(h,\bar h)+f_{uu}+2M_1\operatorname{Re}h]$($a=\varepsilon V_0/2$),频率梯项对共轭临界通道作 deflation(该通道即 $\pi$ 非微扰处理的泵浦通道)。
- 高次亚谐($\omega_p\approx2\omega_0/n$)区宽 $\propto\varepsilon^n$ 可忽略;和频组合阈值实测为单频百余倍;差频组合因两模式阻尼同号不存在。
- **验证**:GFL 5 组 ≤0.5%;GFM 含二阶修正后 ≤0.4%。

### N2 吸引域边界触及平衡点(仅亚临界)

对象链:亚临界 Hopf → 不稳定极限环(半径 $r_c$)→ 周期强迫下延拓为回归映射的不稳定不变闭曲线 $U(\theta)$(Fourier 配点 + Newton 求解 $P_\varepsilon(U(\theta))=U(\theta+\rho)$)→ 其稳定流形为吸引域边界。

- **精确判据**:临界幅值 $\varepsilon_c$ 处存在从平衡点渐近于闭曲线的异宿轨道。数值实现:从平衡点积分,以对闭曲线的最小距离为着陆量;实测着陆残差 $10^{-6}$–$10^{-8}$,判据误差 ≤0.01%,失谐比 0.60–0.92 全域验证。
- **一阶判据**:投影曲线 $\zeta(\theta)=\langle p,\,U(\theta)-x_{\rm eq}\rangle$ 关于原点的卷绕数由 1 变 0 的幅值。中等失谐(≥0.9)21/21 组 ≤0.2%;深失谐系统性偏迟(0.75 处 +0.9%、0.70 处 +1.2%、0.60 处 +2.3%),偏差源于稳定流形在模式平面内超出闭曲线的横向延展。
- **动力学特征**:平衡点线性阻尼全程不变(突发型,无阻尼劣化前兆);阈上逃逸时间发散 $t_{\rm esc}\sim(\varepsilon-\varepsilon_c)^{-0.9}$——有限观测窗把阈值读高,阈值测量须逃逸时间感知。
- **协议纪律**(实测教训):判据与测量必须逐组核对驱动频率;模型侧与实测侧的失稳事件判据须逐字一致;测量值跨脚本转录保留全精度。
- 超临界机器无此机制:响应饱和,实测至 40% 电压包络振荡不失步(线性外推高估约 50 倍)。

### N3 慢通过逃逸(动态分岔)

$$\dot z=\lambda(u(t))\,z-\langle p,\partial_ux_{\rm eq}\rangle\dot u-\langle p,\partial_uq\rangle\dot u\,z+\ell_1(u)|z|^2z$$

- 系数为冻结族沿路径的已知函数;阈值 = 该方程的逃逸边界(判决为路径泛函,无代数闭式,机理即积累)。
- 精度阶梯(每级显式):基础形式 ≤0.9%(多数工况);补受迫偏置×二次项耦合与解析五次($\ell_2$)后再收;最后约 1% 为稳定子空间中心流形的非准静态滞后,以随瞬时平衡点平移的完整五阶 Taylor 模型闭合,并要求与实测判据逐字一致 → 全部 ±0.0–0.9%;GFM 侧(路径参数为功率指令)≤0.2%。
- 速率 → 0 极限连续退化为冻结判据;冻结前兆理论是本带的零速率观测论。

### N4 过渡带(旋转数锁定)

- 闭曲线旋转数 $\rho(\varepsilon)$ 扫过有理数集,低阶有理数附近为 Arnold 舌;失稳集为区间族。
- 确定性结论仅下包络 $\varepsilon_{\rm env}(\omega_p)=\inf\{\varepsilon:\text{失稳}\}$;包络以上逐点判。非单值性为对象性质,非精度缺口。低阻尼 GFM 强迫背景下的多摆逃逸条带同属此类。

### 自治侧补充判据

- 暂态阈值:GFM 能量边值问题(沿逃逸路径含滤波弛豫)≤0.2%;GFL 位移射线 ∩ 不稳定极限环 Floquet 稳定平面族 ≤1%。
- 潜伏时长 $t\approx\kappa^{-1}\ln(A_{\rm vis}/d_0)$,$\kappa$ 验证 ≤0.26%(五阶规范形)。

## 4. 完备性论证

稳定性判决由五要素构成,非自治性对每要素的改写即新可能的完备清单;树上节点与之一一对应:

| 要素 | 非自治改写 | 树上位置 |
|---|---|---|
| ① 参考解 | 常数解 → 有界响应;可不存在/多支折叠/共振放大 | 稳定形态 2b;N2 载体 |
| ② 线性化 | LTI 谱 → Floquet 指数;冻结稳定可增长(正向:振动镇定,未开发格) | N1 |
| ③ 判决类型 | 点函数 → 路径泛函;滞后、延迟失稳、短暂越界无害 | N3 与慢跟踪 |
| ④ 全局几何 | 边界运动(吞没)+ 边界对象新分岔(锁定/缠结) | N2、N4 |
| ⑤ 有限位移 | 快照隶属 → 相位依赖、被侵蚀 | 自治侧暂态格的非自治延拓(交叉项,见 §7) |

无第六要素;单频为原子(多频丰富各行不加新行);随机输入为 ③④ 的随机版本(范围外,共用几何骨架)。

## 5. 两族机器对照(两个结构根贯穿全树)

**根一(阻尼来源)**:GFL 刚度阻尼同源($V\cos\theta^\ast$ 乘性绑定);GFM 阻尼独立常数、经滤波折损。
**根二(内电势)**:GFL 无自持电压($V$ 双重进入);GFM 自持 $E$($V$ 单重,下垂限渗)。

| 树上位置 | GFL(亚临界,双通道) | GFM(超临界,纯频率型) |
|---|---|---|
| 自治 $\alpha\le0$ 越界方式 | 振荡型(有前兆) | 鞍结型(静默盲区) |
| 自治 $\alpha>0$ | 局部稳定,$r_c$ 有限 | 近全局 |
| 暂态边界对象 | 不稳定极限环稳定流形(经典能量法失配) | 鞍点稳定流形(经典同构) |
| N1 越阈后 | 跑飞 | 有界倍周期振荡 |
| N2 | **主要失稳通道,无前兆** | 无(响应饱和) |
| 响应折叠 | 被 N2 遮蔽不可达 | 窄窗内有,有界跳变 |
| N3 | 有 | 有;穿 Hopf 仅有界萌生 |
| 事故形态 | 失步 或 直流电压崩溃(按参与因子族) | 仅失步 |
| 危险工况 | 重载/弱网(各阈值同角塌缩) | 轻载(参数舌阈值最低) |

适用限定:GFM 结论限独立阻尼类;下垂系数增大同时推向 GFL 化并削弱饱和保护,须重查 N2。

## 7. 范围边界与交叉项

- **排除项**:单调漂移至冻结失稳(平凡);大扰动初值问题(经典暂态,自治侧已给判据);随机扰动(范围外,复用几何骨架)。
- **交叉项(振荡背景上的暂态)**:有限位移落在 $\varepsilon\ne0$ 背景上时,初值与边界都在动,阈值为强迫相位的函数且被侵蚀——共振背景 1–2% 电压振荡侵蚀 10–15% 裕度,偏共振约 0.8%;低阻尼 GFM 部分工况退化为多摆条带。$\varepsilon\to0$ 连续退化为纯暂态。
- **可用运行域**:$\mathcal U(\varepsilon,\omega_p)=\{u_0:\varepsilon_{\rm crit}(u_0;\omega_p)>\varepsilon\}\subsetneq\{u_0:\alpha(u_0)>0\}$;$\varepsilon\to0$ 时涨回小信号稳定域。小信号域本身不缩小;缩小的是状态空间安全邻域($r_c\propto\sqrt\alpha$)与非零扰动环境下的可用域。

## 8. 频带边界的认识论地位

| 引用数字 | 身份 |
|---|---|
| $\omega_p\approx2\omega_0$ | 舌根标签;边界由舌不等式**自定义**(精确) |
